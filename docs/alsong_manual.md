# 알송 3.56 사용 설명서 (변환본 — 페이지별 정리)

> 변환 방법 안내
> - `anydoc`(firecrawl) 변환은 이미지 전용 페이지 때문에 exit 3(OCR 필요)으로 중단됨. 외부 OCR(`--ocr hosted`)은 문서를 외부 서비스로 업로드하므로 사용하지 않음.
> - `pdftotext`는 텍스트 레이어의 한글이 깨져(글리프 누락) 사용 불가.
> - 따라서 PyMuPDF로 전 페이지를 렌더링해 시각 판독했음. 아래는 원문 전사가 아니라 **페이지별 요약**이며, 메뉴 명칭·단축키·수치는 원문 표기를 따름.
> - 공백 구분 페이지(5, 8, 15, 21, 29, 39, 41, 67)는 장 표지이며 79쪽은 고객센터 정보만 있음.

## 1. 소개 (p.2, 6-7)
- 설치 환경: Windows 10/11 (32/64bit), CPU 2GHz 듀얼코어 이상(권장 3GHz 쿼드), RAM 4GB(권장 8GB), 저장공간 1GB(권장 2GB).
- 고객지원: 알툴즈 홈페이지 고객센터, altools@estsoft.com, 전화 1544-8209.
- 주요 기능 소개: 색상 테마, 미니 리모콘, 다양한 음악·재생목록 형식 재생, 10밴드 이퀄라이저·PRESET, 폴더 구조 재생목록, 압축 파일 재생, 분리모드, 실시간 싱크가사, 재생목록 관리, MP3 플레이어 전송, 벨소리(*.mmf) 제작, SKT 통화연결음 설정, 녹음/어학, 데스크톱 가사창, 글로벌 핫키, PC 자동 종료, 투명도, 태그 관리.

## 2. 설치 및 제거 (p.9-14)
- 알매니저(알툴즈 통합 관리 프로그램)가 있으면 알매니저에서 알송 [설치하기] → 설치 시작 → 완료 후 [제품 실행].
- 알매니저가 없으면 홈페이지 설치 패키지 실행 → 사용권 계약 동의 → 알매니저 자동 설치 → 알송 자동 설치.
- 제거: Windows 설정 > 앱 > 설치된 앱에서 알송 삭제.

## 3. 알송 인터페이스 (p.15-20)
- 메인 창: 앨범 정보 보기 모드(①)와 재생 시간 보기 모드(②) 전환, 재생 컨트롤, 볼륨, 재생목록·싱크가사 창 열고 닫기, 미니모드, 좌우 크기 조절.
- 싱크가사 창: 실시간 싱크 가사 표시, 가사 등록·수정·추천·신고 버튼.
- 재생목록 창(Now Playing): 목록 표시, 파일/폴더 보기 전환, 재생그룹 구성, MP3 플레이어 전송.
- 분리모드(p.18): 메인 창, 싱크가사 창, 재생목록 창을 개별 창으로 구성. 메뉴 보기 > 분리모드 또는 우클릭.
- 미니모드(p.19): 메인 창의 기본 기능만 담은 최소 크기 모드. 분리모드에서 메인 창 더블클릭, 메뉴 보기 > 미니모드, 우클릭.
- 알송 리모콘(p.20): 작업 표시줄에 재생 컨트롤 표시. Windows 10 이하에서만 지원(Windows 11은 작업 표시줄 도구 모음 미지원). 환경설정에서 사용 설정.
- 데스크톱 가사창(p.20): 바탕화면에 가사 표시. 환경설정에서 사용, 화살표 버튼으로 버튼 숨김.

## 4. 메뉴 (p.21-28)
- 파일(p.22-23): 열기(폴더·파일, URL Ctrl+L), 추가(폴더·파일 N, URL Ctrl+N), 기본 열기 형식, 사운드 효과, 재생목록 백업/복원, 업데이트(U), 종료(X, Alt+F4).
- 재생(p.24-25): 이전곡(Z), 재생/일시정지(X/Space), 정지(V), 다음곡(B), 뒤로(Left)·앞으로(Right) 이동, 반복 재생(한곡/전체/폴더/끄기), 무작위 재생, 소리 높임(Up)·낮춤(Down)·음소거(M), 속도 조절(느리게 Q, 빠르게 E, 정상 W), 구간 반복.
- 보기(p.26): 분리모드, 미니모드, Now Playing 창(Ctrl+P), 싱크 가사 창(Ctrl+R), 데스크톱 가사 창, 항상 위에, 시간 표시 방법(경과/남은), 파일명 일괄 정리(Shift+3), 자동 태그/태그 일괄 수정(Ctrl+3), 파일 정보 보기/수정(Alt+3).
- 도구(p.27): 스킨 설정(알송v3 블랙펄/크레용/파스텔/팔레트 4종, 스킨 설정 창), 많이 들은 음악, 폰꾸미기(Ctrl+G), 사운드 효과, 녹음/어학(Shift+R), 싱크 가사(등록/추천/신고/수정), 환경 설정(F4).
- 도움말(p.28): 도움말(F1), 자주 묻는 질문, 고객 상담, 알툴즈·이스트소프트 홈페이지, 알송 정보.

## 5. 알송 기본 기능 (p.30-38)
- 음악 가져오기(p.30): 메뉴 파일 > 열기/추가, 폴더·파일 또는 URL 입력. 열기는 기존 목록을 대체하고 추가는 유지.
- 음악 재생(p.31): 재생 메뉴 또는 X 키, 재생 목록에서 Enter. 압축 파일 재생 지원. 이전 곡 규칙: 재생 후 2초 이내 이전 곡, 3초 이후는 현재 곡 처음부터.
- 소리/속도 조절(p.32): 메뉴·키보드·볼륨 드래그로 소리 조절, 속도 조절(Q/E/W).
- 재생 설정(p.32-33): 반복 재생(한곡·전체·폴더·끄기), 무작위 재생(순차 재생 전환 버튼 포함).
- 현재 재생목록(p.33): 폴더 보기/파일 보기 전환, 폴더 모두 열기/닫기(Ctrl+Shift+O/P), 재생목록 검색.
- 스킨 설정(p.34): 4가지 기본 스킨 중 선택, 스킨 설정 창에서 미리보기 후 적용. 알툴즈 갤러리 서비스는 2012년 3월 14일 종료.
- 파일 정보 보기(p.35-36): 파일 정보 창(기본 정보·가사 탭), 지원 확장자 mp3, mp4, ogg, wma, asf, m4a. 앨범 이미지 영역 클릭으로 실행. MP3 파일에 가사를 넣으면 모바일 플레이어에서 가사 표시.

## 6. 기타 확장 기능 (p.37-66)
- 가사 불러오기(p.37): 파일 정보 창의 가사 탭에서 직접 입력·수정하거나 '가사 불러오기'로 채움. 가사 내장 MP3는 모바일에서 가사 표시.
- MP3 플레이어 전송(p.38): 재생목록에서 목록 선택 후 우클릭 > MP3 플레이어 전송 또는 버튼 클릭, 전송 시작/중지.
- 사운드 효과(p.40-41): 입체 사운드(MEX) 켜기/끄기(Power), 이어폰 모드(입체음향·웰빙·와이드·라이브, 서라운드·베이스 조정), 스피커 모드(스피커 거리 조절), 프리셋 저장.
- 녹음(p.42-44): 녹음/어학 창에서 녹음 시작·일시정지·정지. 녹음 설정 탭(입력 장치·볼륨, 저장 설정: OGG·WAV 포맷, 음질, 저장 위치, 파일명 변수 %Y %M %D %h %m %s).
- 어학 기능(p.45-46): 재생 중 곡 정보, 속도 -50%~100%, 키 -12~+12(기본 0), 반복 설정, 거꾸로 재생, 구간 반복 시작·종료 위치 설정. 초기화 버튼 또는 단축키 W(속도), S(키).
- 싱크 가사(p.47-57): 싱크 가사 보기(Ctrl+R), 가사 등록 마법사(Ctrl+E: 등록 여부 확인 → 음악 정보 입력 → 검색 및 미리듣기 → 가사 연결 → 싱크 맞추기(Alt+S, 1줄/2줄/3줄 단위) → 수정자 정보 → 완료; 서버 등록 후 가사 관리자 승인). 가사 수정(p.53), 추천(p.56, ★), 신고(p.57).
- 자동 태그/태그 일괄 수정(p.58-61): 파일 정보 창의 자동태그 버튼, 태그 검색 창(키워드 검색), 여러 곡 자동 태그(Ctrl+3: 자동 태그 탭 / 태그 일괄수정 탭), 파일명 정리 버튼.
- 파일명 일괄 정리(p.62-63): 형식 선택(가수-제목 등, 직접 편집 가능: ### 순서 번호, 태그 변수, 텍스트 추가), 정렬 옵션, 적용·저장. 태그 정보가 없으면 적용되지 않음.
- 폰꾸미기(p.64-66): 재생 중 곡을 벨소리 파일(*.mmf)로 변환. 구간 선택(0.1초 단위 조정), 벨소리 길이 1~90초, 볼륨 평준화·페이드 인/아웃(3초), 음질(40화음 모노/스테레오 보통, 64화음 모노/스테레오 고음질), 파일 크기 표시, 미리듣기, 저장(휴대폰 데이터 케이블로 옮김).

## 7. 환경설정 (p.67-77)
- 일반 설정(p.68): 항상 위에 보기, 실행 시 자동 재생, 싱크 가사 서버 접속, 윈도우 시작 시 자동 실행, 작업 표시줄 제목 흐르기, 표시 방법(작업 표시줄+트레이), 탐색기 더블클릭 동작, 알송 리모콘 설정.
- 제목 형식(p.69): Now Playing 제목 표시 형식(가수-제목 등 ID3 항목 조합), Free CDDB 서버 연결(오디오 CD 삽입 시 재생목록 가져오기).
- 재생 설정(p.70): 앞/뒤로 이동 시간 단위(1~100초), Output 버퍼 사이즈(3000), 종료 시 재생 위치 기억(스트리밍 제외), 폴더 보기(유지/자동 펼치기/자동 닫기), 폴더 추가 시 하위 폴더 포함, 압축 파일 지원, Now Playing 글꼴·크기·색.
- 가사 설정(p.71): 싱크 가사 글꼴·크기·색·정렬, 데스크톱 가사 옵션(글꼴, 색, 정렬, 보기 방식 3줄, 항상 보이기).
- 핫키 설정(p.72): 핫키 사용 여부, 기능별 키 변경(기본 Ctrl+Alt 조합), 멀티미디어 키보드 지원.
- 소리 효과(p.73): 마스터 볼륨, 크로스페이드(1~12초), 노멀라이즈, 어학 단축키 증감 단위(속도 1%, 키 1).
- 스킨 설정(p.74): 스킨 변경, 색상·채도 조절, 투명 윈도우 사용 및 투명도(1.x·2.x 사용자 스킨은 3.0에서 미지원).
- 연결 파일(p.75): 확장자별 파일 연결(Windows 10 이상, .aac 기본 해제). 연결 변경 알림.
- 목록 설정(p.76): 최근 들은 음악(최대 100개, 최근 2주 이내), 많이 들은 음악(재생 횟수 3회 이상).
- 기타 설정(p.77): 전원 관리(설정 시간 후 시스템 종료 또는 절전), 자동 태그 정보 공유, 앨범명.jpg 표시.

## 9. 지원 파일 형식 요약
- 재생: MP3, WAV, CDA, MOD, OGG, WMA (p.6). 재생목록: M3U, PLS, ASL (p.6).
- 압축 파일 직접 재생: zip, alz, rar, egg, sab, 7z (p.6, p.31).
- 파일 정보 편집: mp3, mp4, ogg, wma, asf, m4a (p.35). 자동 태그: mp3, wma, ogg (p.59).
- 파일 연결 목록(p.75): mp3, mpga, ogg, wav, wma, ape, flac, m4a, cda, s3m, mod, asl, m3u, pls, sab (.aac 기본 해제).
- 녹음 출력: OGG, WAV (p.44). 벨소리 출력: MMF (p.66).

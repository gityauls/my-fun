## 3. 단축키

전체 목록은 `alsong_manual.md` 8절 참조. 핵심:
- 재생: X/Space 재생·일시정지, V 정지, Z 이전, B 다음, Left/Right 이동, Up/Down 볼륨, M 음소거, Q/E/W 속도
- 보기: Ctrl+P 재생목록, Ctrl+R 싱크 가사, Ctrl+E 가사 등록, Ctrl+3 자동 태그, Alt+3 파일 정보, Shift+3 파일명 정리, Shift+R 녹음/어학, Ctrl+G 폰꾸미기
- 기타: L 열기, Ctrl+L URL 열기, Ctrl+O/S 목록 열기·저장, F4 환경 설정, F1 도움말, Alt+F4 종료
- 어학·가사: W/S 속도·키 초기화, Alt+S 싱크 맞추기
- 글로벌 핫키(Ctrl+Alt 조합, 기본 사용 해제): PageUp, Insert, End, PageDown, Left, Right, R, S, M, Up, Down, BackSpace, D

## 5. 온라인 서비스 의존 기능

ESTsoft(알툴즈) 서버·온라인 서비스에 의존하는 기능 ID:

- **[온라인] 명시**: A-1 (알매니저·설치 패키지 다운로드), D-1 (실시간 싱크가사 서비스), D-2 (D-1 데이터 의존), D-3 (가사 등록·서버 승인), D-4 (가사 수정·서버 반영·승인), D-5 (가사 추천·신고 통계), K-1 중 "싱크 가사 서버 접속" 옵션, K-6 (Free CDDB 서버), K-9 (홈페이지·고객 상담·업데이트)
- **[온라인 추정] 매뉴얼에 명시 안 됨**: H-3, H-4, H-5 (자동 태그·태그 검색은 외부 태그 DB 조회로 보이나 매뉴얼은 서버 여부를 밝히지 않음), K-8 (자동 태그 정보 공유)
- **[외부] ESTsoft 외 서비스**: G-5 (SKT 통화연결음 서비스)
- **서비스 종료**: 알툴즈 갤러리(스킨 다운로드)는 2012년 3월 14일 종료, 그 스킨은 3.0부터 미지원 (I-5)
- **온라인 여부 불명**: D-6 가사 불러오기 버튼의 출처 (매뉴얼에 기재 없음)

**온라인 의존 ID 요약**: A-1, D-1, D-2, D-3, D-4, D-5, K-1(싱크 서버 옵션), K-6, K-9 · 추정: H-3, H-4, H-5, K-8 · 외부: G-5 · 확인 필요: D-6

# 5-D 여러 곡 태그 설계

> 시안 승인 2026-11-02 ("시안대로 진행시켜"). 시안 `docs/images/stage5d_mockup.png`, 실제 화면 `docs/images/stage5d_real.png`.

## 1. 여는 법

재생목록에서 곡을 고르고 우클릭 → "여러 곡 태그 고치기… (N곡)" 또는 Ctrl+T. 고른 곡이 없으면 커서 줄 한 곡. 창은 창 모달이라 열려 있는 동안 재생목록은 바뀌지 않는다. MP3가 아닌 곡은 빼고 머리줄에 알린다.

## 2. 탭

| 탭 | 동작 |
|---|---|
| 공통 칸 | 가수·앨범·년도·장르: 체크한 칸만 모든 곡에 같은 값. 모두 같은 값이면 미리 채워 두고, 다르면 "(여러 값 · 그대로 둠)". 칸에 글자를 치면 체크가 켜진다. 그림: [그림 넣기…] 또는 Ctrl+V(글자 칸 밖) |
| 파일 이름 → 태그 | 처음 열 때 "이 방법으로 채우기"가 켜진다. 자동 짐작(`bulktag.guess_auto`): `[가수]제목`, `가수 - 제목`(세 번째 조각부터 버림), 앞 번호 1~3자리는 트랙, 괄호 군말 제거. 직접 모양: `%가수% %제목% %앨범% %년도% %장르% %트랙%`(영어 낱말도 됨), 빈칸은 있어도 없어도 된다. "비어 있는 칸만 채우기", "밑줄(_)을 빈칸으로"(기본 켬) |
| 붙여 넣기 → 태그 | 글을 넣으면 켜진다. 빈 줄을 빼고 윗줄부터 표의 곡에 차례로. 줄 수 ≠ 곡 수면 저장 막음(빨간 글). 자동: 앞 번호는 트랙, 나머지는 제목. ↑↓로 표의 곡 순서를 바꾼다 |
| 트랙 번호 | 처음 열 때 켜진다. 표 순서대로 시작 번호부터, "3/12"처럼 전체 곡 수 붙이기 고름 |
| 파일 이름 바꾸기 | **저장된** 태그로 `가수 - 제목.mp3`. 저장하지 않은 바뀐 값이 있으면 "먼저 [저장]을 누르세요". 표에 "새 파일 이름" 칸이 나온다(지금 이름과 같음 / 가수·제목 필요 / 같은 이름 있음). 겹치는 곡은 건너뛴다. [한 번에 되돌리기]는 이 창에서 방금 바꾼 것만, 뒤에서부터 |

## 3. 값 합치는 순서

원래 값 → 파일 이름 → 붙여 넣기 → 트랙 번호 → 공통 칸 → 표에서 직접 고친 칸. 노란 칸은 원래 값과 다른 칸.

## 4. 저장

- `PlayerController.save_many`: 곡마다 5-A와 같은 안전 저장. 듣는 중인 곡은 내렸다가 같은 자리로. 실패한 곡은 건너뛰고 모아서 빨간 글로 몇 곡·어떤 곡인지 알린다.
- 저장한 곡은 파일에서 다시 읽어 원래 값으로 삼고, 탭의 "채우기" 체크는 모두 끈다. 창은 열린 채로 남는다.
- `rename_many` / `undo_many`: 5-C의 안전장치(덮어쓰기 없음)를 쓰고, 재생목록·지난 곡·즐겨찾기 경로도 함께 고친다. 바꾼 기록은 rename_log.txt에도 남는다.
- 태그 저장 되돌리기와 여러 곡 MusicBrainz 찾기는 넣지 않는다.

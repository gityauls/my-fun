# 5-D 여러 곡 태그 설계 (고침판)

> 첫 시안(탭 다섯 개, `docs/images/stage5d_mockup.png`)은 2026-11-02 사용자 확인에서 "쓰기 어렵고 트랙은 원치 않음"으로 바뀌었다.
> 고침 시안 `docs/images/stage5d2_mockup.png` 승인("시안처럼 진행"), 실제 화면 `docs/images/stage5d_real.png`.

## 1. 사용자 목적

파일을 전부 `가수 - 제목`으로 통일한다. 지금 이름은 `가수 - 제목`, `[가수] 제목`, `제목-가수`가 섞여 있다.
트랙 번호는 쓰지 않는다(앞 번호가 있으면 재생목록 정렬이 보기 싫다).

## 2. 여는 법

재생목록에서 곡을 고르고(Ctrl+A) 우클릭 "여러 곡 태그 고치기… (N곡)" 또는 Ctrl+T. 창 모달. MP3만.

## 3. 이름 정리 탭 (기본)

표: 지금 파일 이름 · 가수 · 제목 · 앨범 · 그림(있음/없음 붉은 글) · 새 파일 이름 · 알림.
[태그 저장 + 이름 바꾸기 (N곡)] 한 번으로 가수·제목 태그를 쓰고 `가수 - 제목.mp3`로 바꾼다. 같은 이름이 있으면 이름은 그대로.
[이름 한 번에 되돌리기]는 이 창에서 방금 바꾼 이름만.

`bulktag.tidy_names` 규칙:
- `[가수]제목`·`가수 - 제목`(세 번째 조각부터 버림)·`제목-가수`(빈칸 없는 하이픈 하나, 양쪽 두 글자 이상).
- 앞 번호(02.)·밑줄·앞 괄호 군말((홍대클럽))은 뺀다. 트랙 태그는 넣지도 지우지도 않는다.
- 어느 쪽이 가수인지: 기존 가수 태그와 같은 쪽 → 다른 곡에서 가수로 쓰인 이름(다른 곡의 태그, `가수 - 제목`·`[가수]`의 가수) → 모르면 `제목-가수`로 보고 **주황 줄**.
- 기존 태그가 빈칸·대소문자·괄호만 다르면 태그 표기를 쓴다(`너만은 모르길`, `(You Drive Me) Crazy`, `Chuck`).
- 파일 이름과 태그의 가수가 아예 다르면 주황 줄 "태그의 가수는 '투투' · 확인".
- 가수가 없으면 주황 줄 "가수를 모름 · 직접 입력".
- **겹친 가수 합치기**: 한 칸에 같은 가수가 겹치면 하나로(`이승철,이승철` → `이승철`). 다른 가수들은 그대로.
- **같은 가수 표기 통일**: `한글(영어)` > `한글` > `영어`. 고른 곡들(파일 이름과 태그)에 `이승철(Lee Seung Chul)`이 하나라도 있으면 `이승철`·`Lee Seung Chul`·`Lee Seung Chul(이승철)`을 모두 그것으로. 둘을 이어 주는 표기가 없으면 한글·영어가 같은 가수인지 알 수 없어 그대로 둔다. 가수 쪽 끝의 다른 글자 괄호는 별칭이라 남기고, 제목 쪽 괄호는 뺀다.
- 주황 줄은 확인해야 바뀐다: 줄을 골라(여러 줄) [↔ 앞뒤 바꾸기] 또는 [이대로 맞음], 또는 가수·제목 칸을 두 번 눌러 직접 고침.

## 4. 공통 칸 탭

가수·앨범·년도·장르: 체크한 칸만 모든 곡에. 칸에 글자를 치면 체크가 켜진다. 그림: [그림 넣기…] 또는 Ctrl+V. [저장 (N곡)].

## 5. 그림 없는 곡 (사용자 추가 요청)

목록 ▸ 그림 없는 곡 ▸
- 찾아서 붉은 글로 표시: 뒤에서 `tagwrite.has_cover`(태그 속 그림, 없으면 같은 폴더 그림 — 곡 정보 창과 같은 기준, MP3는 태그 머리만 읽음)로 찾고 상태 줄에 곡 수.
- 붉은 곡만 고르기 / 붉은 곡에 한 번에 그림 넣기…(공통 칸 탭으로 열림) / 붉은 표시 지우기.
- 표시는 임시(저장 안 함). 곡 객체를 따라가서 줄이 옮겨지거나 이름이 바뀌어도 남는다. 그림을 넣으면(곡 정보 창·여러 곡 태그 어느 쪽이든) 그 곡은 다시 검은 글.
- 색 우선순위: 없는 파일 회색 > 그림 없음 붉은색 > 즐겨찾기 파란색.

## 6. 저장

`save_many`(5-A 안전 저장, 듣는 중인 곡은 같은 자리로), `rename_many`/`undo_many`(5-C 안전장치, 재생목록·지난 곡·즐겨찾기 경로 함께). 실패한 곡은 건너뛰고 빨간 글로 몇 곡·어떤 곡인지.

## 7. 고침 (2026-11-02 사용자 확인 뒤)

- 하이픈이 여럿인 이름(`가수 - 제목 - 꼬리`, `가수-제목 - 꼬리`, `제목-가수-꼬리`)은 모든 조각으로 나눠, 다른 곡의 가수·기존 태그로 가수 조각을 찾고 옆 조각을 제목으로 삼는다. 늘 주황 줄(`하이픈이 여러 개 · 확인`). 셋 이상일 때 마지막 조각은 이 곡 태그만으로 가수로 보지 않는다. 한쪽이 한 글자인 하이픈(`Jay-Z`)은 나누지 않는다.
- 표의 지금 파일 이름·새 파일 이름·알림 칸은 두 번 누르면 읽기 전용 글자 칸이 떠 긁어 복사할 수 있다. 칸을 고르고 Ctrl+C도 된다.

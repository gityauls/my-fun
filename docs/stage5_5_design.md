# 5.5단계 설계: 디자인 개편

승인: 2026-11-05 (사용자). 시안: https://claude.ai/artifact/VvSZBpVxWHySuhUmdVGEHQ , 복사본 `docs/design55/mockup.html`.

## 목표
지인에게 선물해도 될 모습으로 화면을 바꾼다. 재생·라디오·태그 기능은 바꾸지 않는다.

## 결정 사항
| 항목 | 결정 |
|---|---|
| 기본 창 | 380×620, 둥근 모서리 20px, Windows 테두리 없음, 직접 만든 상단바 |
| 탭 | 지금 재생 / 재생목록 / 라디오 / 음향 효과 (아이콘 + 글자) |
| 하단 재생 띠 | 지금 재생 탭 말고 세 탭의 맨 아래에 표시. 그림, 제목, 이전·재생·다음, 진행 막대 |
| 미니 모드 | 긴 막대형 680×104, 모서리 24px. 나중에 캘린더 위젯으로 쓴다 |
| 테마 | 12종 (J 제외), 기본 라이트 모던, 설정 창에서 고른다 |
| 글꼴 | Noto Sans KR Regular·Bold를 프로그램에 포함 (OFL). 없으면 맑은 고딕 |
| 그림 없는 곡 | 테마 색으로 그린 언덕 그림 |
| 라디오 그림 | 테마 강조색 그라데이션 + 라디오 아이콘 |

### 테마 목록
`light` 라이트 모던, `dark` 다크 시티, `mid` 네추럴 미드, `c` 앨범 색, `d` 흑연, `f` 서리, `g` 세이지, `h` 남보라, `i` 숲과 테라코타, `k` 흙과 올리브, `l` 노을, `m` 청록과 구리.

색값은 `docs/design55/themes1.js`(앞 3종), `themes2.js`(나머지, J는 쓰지 않음)가 원본이다.

## 시안에서 옮기며 달라진 점
- **정지 버튼을 없앤다.** 재생 버튼과 제목을 오른쪽 클릭한 메뉴에 "정지"와 "라디오로"/"MP3로"를 둔다. 단축키 V는 그대로다.
- **재생목록 줄의 곡 길이를 표시하지 않는다.** 곡 길이는 재생해야 알 수 있기 때문이다.
- **하트:** 지금 나오는 곡(또는 방송)의 즐겨찾기를 켜고 끈다. 곡은 기존처럼 맨 위로 올라간다.
- **Ctrl+E:** 음향 효과 탭과 지금 재생 탭을 오간다. "음향 효과 칸 보이기" 메뉴는 없앤다. 접기·펼치기도 없애고 늘 펼친 상태로 쓴다.
- **미니의 네모 버튼**은 보통 보기, **목록 버튼**은 보통 보기 + 재생목록 탭이다.
- **곡 정보·여러 곡 태그 창은 지금 모습을 유지한다.** 테마를 적용하지 않는다.

## 구조
- `core/themes.py`: `Theme` 데이터와 12종, 앨범 색 계산. Qt 없음.
- `ui/style.py`: 테마 → QSS. 패널 안 위젯만 objectName으로 지정해 대화상자에 번지지 않게 한다.
- `ui/fonts.py`, `ui/glyphs.py`, `ui/title_bar.py`, `ui/icon_tabs.py`, `ui/now_strip.py`, `ui/settings_dialog.py`: 각 부품.
- `PlayerPanel`은 기존 위젯 이름을 유지하고 배치만 옮긴다. 미니 전환은 같은 위젯을 다른 배치로 옮긴다.
- 테두리 없는 창은 `__main__`에서 켠다. 6단계에서 캘린더에 끼울 때는 끄기 위해서다.

## 앨범 색 테마
곡이 바뀔 때만 계산한다. 그림의 채도 높은 픽셀로 색상(hue)을 뽑아 어두운 바탕과 밝은 강조색을 만든다. 같은 색이면 다시 적용하지 않는다. 그림이 없는 곡과 라디오는 기본 보라(`#C9B6FF`)를 쓴다.

## 하지 않는 것
창 그림자, 유리 흐림, 대화상자 테마, 사용자 지정 그림 선택.

## 저작권
아이콘 모양은 Lucide(ISC) 기반, 글꼴은 Noto Sans KR(OFL). 라이선스 파일을 함께 넣는다. 시안 예시 그림(구름, 바다, 밤 도시)은 프로그램에 넣지 않는다.

# 5.5단계 설계: 디자인 개편

승인: 2026-11-05 (사용자). 시안: https://claude.ai/artifact/VvSZBpVxWHySuhUmdVGEHQ , 복사본 `docs/design55/mockup.html`.

## 목표
지인에게 선물해도 될 모습으로 화면을 바꾼다. 재생·라디오·태그 기능은 바꾸지 않는다.

## 결정 사항
| 항목 | 결정 |
|---|---|
| 기본 창 | 380×680, 둥근 모서리 20px, Windows 테두리 없음, 직접 만든 상단바. 크기는 340×650 ~ 460×780 안에서만 바뀌고 최대화는 없다 |
| 탭 | 지금 재생 / 재생목록 / 라디오 / 음향 효과 (아이콘 + 글자) |
| 재생 띠 | 지금 재생 탭 말고 세 탭의 탭 바로 아래에 표시 (높이 86). 그림, 제목, 이전·재생·다음, 아래쪽 진행선 |
| 미니 모드 | 긴 막대형 830×104, 모서리 24px |
| 테마 | 12종 (J 제외), 기본 라이트 모던, 설정 창에서 고른다 |
| 글꼴 | Windows 기본 맑은 고딕 (Malgun Gothic). 프로그램에 글꼴을 넣지 않는다. 시안이 굵은 곳은 굵게 |
| 그림 없는 곡 | 테마 색으로 그린 언덕 그림 |
| 라디오 그림 | 테마 강조색 그라데이션 + 라디오 아이콘 |
| 상단바 설정 단추 | 작게 보기 단추 왼쪽에 설정(톱니) 아이콘. 미니 모드에는 상단바가 없어 그대로 |
| 작은 미니 단추 | 지금 재생의 하트 옆 작게 보기 단추는 상단바에 같은 단추가 있어도 남긴다 |

최소 창 크기는 340×650이다. 맑은 고딕으로 지금 재생 탭 + 안내 줄을 실제 Windows에서 재면 643이다.

### 3차 수정 (2026-11-06, 사용자 피드백)
시안: https://claude.ai/artifact/K1jCx8AUhQjjYJB46eZgya

- **지금 재생 순서:** 표지, 제목, 이퀄라이저, 진행바, 조작, 소리. 이퀄라이저는 소리에 맞춰 움직이는 막대(32개)이고 색은 테마를 따른다. 창을 세로로 늘리면 이 칸이 함께 커진다.
- **긴 글:** 지금 재생, 재생 띠, 미니 막대의 제목과 가수 줄은 칸을 넘으면 2초 멈춘 뒤 옆으로 흐른다.
- **테마 넘기기:** 표지 양옆(미니 막대 포함)에 마우스를 올리면 `<` `>`가 나타난다. 누르면 바로 바뀌고 저장되며, 끝에 닿으면 처음으로 돈다.
- **미니 항상 위:** 기본 끔. [보기] 메뉴에서 켤 수 있다.
- **재생 띠 바탕:** 연한 강조색(`tint`). 글자 명암비가 7 미만인 테마(I, K)는 `strip_bg`를 쓴다.
- **미니 막대:** 기본 크기 830×104. 높이는 고정이고 폭은 늘릴 수 있다. 곡 이름과 하트 사이에 이퀄라이저(106×44, 막대 16개)를 넣었다. 곡과 라디오 모두 움직인다.
- **테마 단추 크기:** 표지에 비례한다. 지금 재생은 표지 216에 글리프 36, 간격 8, 누르는 칸 52. 미니는 표지 80에 글리프 16, 막대 끝에서 6, 간격 4, 누르는 칸 18.

### 테마 목록
`light` 라이트 모던, `dark` 다크 시티, `mid` 네추럴 미드, `c` 앨범 색, `d` 흑연, `f` 서리, `g` 세이지, `h` 남보라, `i` 숲과 테라코타, `k` 흙과 올리브, `l` 노을, `m` 청록과 구리.

색값은 `docs/design55/themes1.js`(앞 3종), `themes2.js`(나머지, J는 쓰지 않음)가 원본이다.

## 시안에서 옮기며 달라진 점
- **[라디오로]/[MP3로] 미니 버튼은 따로 두지 않고 오른쪽 클릭 메뉴로 옮겼다.**
- **정지 버튼을 없앤다.** 재생 버튼과 제목을 오른쪽 클릭한 메뉴에 "정지"와 "라디오로"/"MP3로"를 둔다. 단축키 V는 그대로다.
- **재생목록 줄의 곡 길이를 표시하지 않는다.** 곡 길이는 재생해야 알 수 있기 때문이다.
- **하트:** 지금 나오는 곡(또는 방송)의 즐겨찾기를 켜고 끈다. 곡은 기존처럼 맨 위로 올라간다.
- **Ctrl+E:** 음향 효과 탭과 지금 재생 탭을 오간다. "음향 효과 칸 보이기" 메뉴는 없앤다. 접기·펼치기도 없애고 늘 펼친 상태로 쓴다.
- **미니의 네모 버튼**은 보통 보기, **목록 버튼**은 보통 보기 + 재생목록 탭이다.
- **곡 정보·여러 곡 태그 창은 지금 모습을 유지한다.** 테마를 적용하지 않는다.

## 구조
- `core/themes.py`: `Theme` 데이터와 12종, 앨범 색 계산. Qt 없음.
- `ui/style.py`: 테마 → QSS. 패널 안 위젯만 objectName으로 지정해 대화상자에 번지지 않게 한다.
- `ui/glyphs.py`, `ui/title_bar.py`, `ui/icon_tabs.py`, `ui/now_strip.py`, `ui/settings_dialog.py`: 각 부품.
- `PlayerPanel`은 기존 위젯 이름을 유지하고 배치만 옮긴다. 미니 전환은 같은 위젯을 다른 배치로 옮긴다.
- 테두리 없는 창은 `__main__`에서 켠다. 6단계에서 캘린더에 끼울 때는 끄기 위해서다.

## 앨범 색 테마
곡이 바뀔 때만 계산한다. 그림의 채도 높은 픽셀로 색상(hue)을 뽑아 어두운 바탕과 밝은 강조색을 만든다. 같은 색이면 다시 적용하지 않는다. 그림이 없는 곡과 라디오는 기본 보라(`#C9B6FF`)를 쓴다.

## 하지 않는 것
창 그림자, 유리 흐림, 대화상자 테마, 사용자 지정 그림 선택.

## 저작권
아이콘 모양은 Lucide(ISC) 기반. 라이선스 파일을 함께 넣는다. 시안 예시 그림(구름, 바다, 밤 도시)은 프로그램에 넣지 않는다.

## 음향 효과 탭의 움짤 (2026-11-07)

탭 아래 빈 곳에 문워크 움짤(`assets/eggs/fx_moonwalk.gif`)을 넣었다. 인물이 검은 옷이라 테마 색을 옅게 섞은 밝은 카드에 올린다. 이스터 에그가 아니라 늘 나오는 장식이다. 재생 여부와 상관없이 탭이 보이는 동안 움직이고, 자리가 80px보다 작으면 그리지 않는다. 공개 배포 전에는 뺀다.

## 숨은 장면 (2026-11-07)

사용 설명서에는 조건을 적지 않는다. 앞의 네 장면은 코드로 찍은 64칸 픽셀 그림이다. 문워크만 사용자가 편집한 움짤을 프레임 줄(`assets/eggs/moonwalk.png`)로 넣었고, 출처는 `assets/LICENSES.md`에 적었다. 공개 배포 전에는 뺀다.

| 조건 | 장면 | 길이 |
|---|---|---|
| 표지 5번 (2.5초 안) | 왕년의 카세트 | 5초 |
| 상단 my-fun 글자 7번 (3.5초 안) | 털복숭이 뭉치 | 4초 |
| 다음 곡 7번 (10초 안) | 지친 햄스터 DJ | 4초 |
| 자정 정각 1분 안에 재생 중, 하루 1번 | 표지 도둑 UFO | 5초 |
| 하루에 댄스곡(장르 태그) 5번 재생, 하루 1번 | 문워크 | 6초 |

- 조건은 `core/easter.py`, 그림은 `ui/egg_sprites.py`, 재생은 `ui/egg_overlay.py`가 맡는다.
- 덮개는 마우스를 통과시키고, 음악은 건드리지 않고, 소리는 내지 않으며, 끝나면 저절로 사라진다.
- 표지 한 번 누름의 곡 정보 창은 0.35초 뒤에 열린다. 연타가 창에 막히지 않게 하려는 것이다.
- UFO는 진짜 표지를 잠시 비우고 사본을 끌어올린다. 끝나면 되돌린다.

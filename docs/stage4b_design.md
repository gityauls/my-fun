# 4-B 설계: 프리셋 추가 · 장르 자동 · 스펙트럼 · 접은 줄 클릭

> 시안: `docs/images/stage4b_mockup.png` (사용자 승인 2026-10-30) · 앞 단계: `docs/stage4_design.md`

## 1. 범위

- 프리셋 8개 추가와 "자동 (장르 따라)".
- 오디오 스펙트럼(막대) — 펼친 칸과 접은 줄에.
- 접은 줄에서 "켜짐/꺼짐"과 프리셋 이름을 눌러 바꾸기.
- **넣지 않는 것:** 장르 짝을 사용자가 고치는 화면, 곡마다 프리셋 기억, 스펙트럼 모양 고르기.
- **미리 확인한 것 (2026-10-30, 이 PC):** 태그의 장르는 이미 읽고 있다(`TrackInfo.genre`). 시험 곡 28곡 중 12곡에 장르가 있다: `Ballad` 3, `Rock` 2, `Dance` 2, `Blues` 2, `알앤비/어반` 1, `R&B` 1, `Classical` 1.

## 2. 프리셋

- 새 프리셋(우리가 정한 값, dB, 31 Hz부터). 기존 10개 뒤에 이 순서로 붙는다.

  | 프리셋 | 값 |
  |---|---|
  | 알앤비 | 5 6 3 0 -1 1 2 2 3 2 |
  | 힙합 | 6 6 3 1 -1 -1 1 1 2 3 |
  | 일렉트로닉 | 5 4 1 0 -2 1 0 2 4 5 |
  | 어쿠스틱 | 2 2 1 1 2 2 3 3 2 1 |
  | 블루스 | 2 3 2 1 0 1 2 1 0 0 |
  | 트로트 | 1 2 2 1 2 3 3 2 1 0 |
  | 라운지 | 2 1 1 0 -1 -1 0 1 1 1 |
  | 라이브 | -1 1 2 3 2 2 3 3 2 1 |

- 프리셋 목록: `자동 (장르 따라)` → 기존 10개 → 새 8개 → `사용자 설정`.

## 3. 자동 (장르 따라)

- **설정값:** 자동을 고르기 전에 쓰던 프리셋(또는 사용자 설정)을 그대로 기억해 둔다. 자동일 때 장르로 프리셋을 못 고르면 이 설정값을 쓴다. 처음부터 자동이면 설정값은 "기본"이다.
- **장르 → 프리셋:** 장르 글자를 소문자로 바꾸고, 아래 표를 위에서부터 보며 낱말이 들어 있으면 그 프리셋이다(먼저 맞는 것). 숫자만 있는 장르(`17`, `(17)`)는 ID3v1 번호표의 이름으로 바꾼 뒤 본다(아래 번호만).

  | 프리셋 | 낱말 |
  |---|---|
  | 알앤비 | `r&b`, `rnb`, `r & b`, `rhythm and blues`, `알앤비`, `soul`, `소울`, `urban`, `어반`, `funk` |
  | 힙합 | `hip`, `rap`, `랩`, `힙합`, `trap` |
  | 일렉트로닉 | `electro`, `edm`, `house`, `techno`, `trance`, `일렉`, `하우스` |
  | 댄스 | `dance`, `댄스`, `disco`, `디스코`, `라틴`, `latin` |
  | 발라드 | `ballad`, `발라드` |
  | 록 | `rock`, `락`, `록`, `metal`, `메탈`, `punk`, `grunge` |
  | 재즈 | `jazz`, `재즈`, `swing` |
  | 블루스 | `blues`, `블루스` |
  | 클래식 | `classic`, `클래식`, `orchestra`, `symphony`, `opera`, `영화음악`, `soundtrack` |
  | 트로트 | `trot`, `트로트`, `성인가요` |
  | 어쿠스틱 | `acoustic`, `어쿠스틱`, `folk`, `포크`, `country`, `컨트리`, `피아노`, `piano` |
  | 라운지 | `lounge`, `라운지`, `chill`, `칠아웃`, `lo-fi`, `lofi`, `ambient`, `앰비언트`, `new age`, `뉴에이지`, `bossa`, `보사노바` |
  | 라이브 | `live`, `라이브` |
  | 보컬 | `vocal`, `보컬` |
  | 팝 | `pop`, `팝`, `가요`, `80년대` |

  ID3v1 번호: 0 Blues, 1 Classic Rock, 2 Country, 3 Dance, 7 Hip-Hop, 8 Jazz, 9 Metal, 13 Pop, 14 R&B, 15 Rap, 17 Rock, 18 Techno, 26 Ambient, 32 Classical, 52 Electronic.
- **곡:** 지금 곡 태그의 장르를 쓴다.
- **라디오:** 해외 추천 방송은 묶음 장르(`재즈`, `클래식`, `Lo-fi` 등)를 같은 표로 보고, 국내 방송과 직접 넣은 방송은 장르 없음(설정값)이다.
- **바뀌는 때:** 곡이 바뀌거나 방송이 바뀔 때 바로 다시 고른다(효과 바꾸기와 같이 부드럽게 넘어간다).
- **화면:** 프리셋 칸에 `자동: 록`처럼 지금 적용된 프리셋 이름이 보이고, 슬라이더도 그 값으로 옮겨진다. 장르로 못 골라 설정값을 쓰면 `자동: 발라드`처럼 설정값 이름이 보인다.
- **자동 중에 밴드 슬라이더를 직접 움직이면:** 자동이 꺼지고, 지금 보이던 값에서 움직인 값이 `사용자 설정`이 된다. 듣는 곳·가로 슬라이더·[켜기]는 자동을 끄지 않는다.
- **[초기화]:** 자동도 끈다(프리셋 "기본").
- 자동 여부는 효과 설정과 함께 저장한다.

## 4. 스펙트럼

- 실제로 들리는 소리(음량·효과 적용 뒤, 내보내기 직전)를 그린다. 효과가 꺼져 있어도 그린다.
- **펼친 칸:** 머리 줄과 이퀄라이저 눈금 사이, 칸 너비 전체, 높이 38 px, 막대 24개.
- **접은 줄:** 듣는 곳 글자 오른쪽, 너비 72 px · 높이 16 px, 막대 12개.
- **막대:** 40 Hz ~ 16 kHz를 로그 간격으로 나눈다. 크기는 -60 dB ~ 0 dB를 0~1로. 각 막대 위에 가는 최고점 표시가 있고 천천히 내려온다.
- **빠르기:** 초당 25번(40 ms). 소리가 없으면(멈춤·정지) 막대가 천천히 내려앉는다.
- **아끼기:** 칸이 숨겨져 있거나 작게 보기면 계산도 그리기도 하지 않는다.
- **색:** 막대 `#4A86D8`, 최고점 `#9DB9E6`.

## 5. 접은 줄 클릭

- 접은 줄: `▸ 음향 효과  {켜짐|꺼짐} · {프리셋} · {스피커|이어폰}  [스펙트럼]`. 듣는 곳이 "끄기"면 그 부분은 없다.
- 효과가 꺼져 있어도 프리셋과 듣는 곳을 보인다(전에는 "꺼짐"만 보였다).
- **켜짐/꺼짐:** 누르면 반대로 바뀐다. 툴팁 `눌러서 끄기` / `눌러서 켜기`.
- **프리셋:** 누르면 목록 순서대로 다음 것: 자동 → 기본 → … → 라이브 → 사용자 설정 → 자동. 사용자 설정 값이 한 번도 없었으면(모두 0) 건너뛴다. 자동일 때는 `자동: 록`처럼 보인다. 툴팁 `눌러서 다음 프리셋`.
- **듣는 곳:** 누를 수 없다(회색 글자).
- 눌리는 글자는 파란 밑줄, 손가락 커서.
- 바꾸면 펼쳤을 때와 똑같이 바로 들리고 저장된다.

## 6. 구조

```text
funplayer/
├─ core/
│  ├─ effects.py    새 프리셋, AUTO, FxSettings.auto, with_auto, applied(genre_preset), next_choice(), summary 바꿈
│  ├─ genre.py      preset_for_genre(text) -> str | None (새 파일, 표와 ID3v1 번호)
│  └─ spectrum.py   band_levels(block, rate, bars) -> np.ndarray, Decay (새 파일, numpy만)
├─ engine/
│  └─ player.py     latest_block() -> np.ndarray | None: 내보낸 마지막 블록 사본 (출력 스레드가 고정 버퍼에 복사)
├─ controller.py    지금 장르 → 적용 프리셋, sync_effects(), applied_preset
└─ ui/
   ├─ spectrum_view.py  SpectrumView(bars, height[, width]) 막대 위젯 (새 파일)
   ├─ fx_strip.py       자동 항목, 적용 이름 표시, 접은 줄 클릭 글자, 스펙트럼 두 곳
   └─ player_panel.py   40 ms 타이머로 스펙트럼 갱신(칸이 보일 때만), 곡·방송이 바뀌면 칸 표시 갱신
```

- **적용 값 계산:** `FxSettings.applied(genre_preset: str | None) -> FxSettings` — 자동이고 genre_preset가 있으면 그 프리셋 밴드, 아니면 설정값 밴드인 사본. 플레이어에는 늘 이 사본을 넘긴다(`build_chain`은 그대로).
- **장르 열쇠:** 컨트롤러는 (곡 경로 또는 방송 id)가 바뀔 때만 다시 계산한다. `_play_index`와 `play_station` 끝에서, 그리고 패널 refresh에서 `sync_effects()`를 부른다(같은 열쇠면 아무것도 안 한다).
- **층 나누기:** core/·engine/·controller.py는 Qt를 import하지 않는다.

## 7. 테스트

- **genre:** 표의 낱말들, 대소문자, 먼저 맞는 것(`Classic Rock` → 록, `Rhythm and Blues` → 알앤비), 숫자 장르, 빈 글자 → None, 시험 곡의 실제 값 7가지.
- **effects:** 새 프리셋 값과 순서, with_auto, applied(있음/없음), 자동 중 with_band → 자동 꺼짐 + 사용자 설정, reset → 자동 꺼짐, next_choice 순서(사용자 설정 건너뛰기 포함), summary(꺼짐에서도 프리셋·듣는 곳, 자동 표시), dict 왕복과 망가진 auto 값.
- **spectrum:** 사인파 → 그 주파수 막대가 가장 큼, 무음 → 0, 길이 다른 블록, Decay가 천천히 내려옴.
- **player:** latest_block이 내보낸 블록과 같다, 출력 전에는 None, 블록 크기가 달라도 된다.
- **controller:** 자동일 때 곡 장르에 맞는 프리셋이 플레이어에 간다, 장르 없으면 설정값, 해외 방송 묶음 장르, 국내 방송 설정값, 같은 곡에서는 다시 안 보냄.
- **화면:** 콤보 `자동 (장르 따라)` 첫 항목·`자동: 록` 표시, 자동 중 슬라이더 → 사용자 설정, 접은 줄 켜짐/꺼짐·프리셋 클릭, 듣는 곳은 클릭 안 됨, 스펙트럼 두 곳 위치, 칸이 숨겨지면 타이머 멈춤, 창 너비 그대로.

## 8. 완료 기준 (사용자 체크리스트)

- [ ] 프리셋 목록에 새 프리셋 8개(알앤비 … 라이브)와 맨 위 "자동 (장르 따라)"가 있다
- [ ] 자동을 고르면 장르가 있는 곡은 그 장르 프리셋(예: 자동: 록), 없는 곡은 설정값으로 나온다
- [ ] 곡을 넘기면 프리셋이 장르에 맞게 바뀐다
- [ ] 해외 추천 방송은 장르 프리셋, 국내 방송은 설정값으로 나온다
- [ ] 자동 중에 슬라이더를 움직이면 "사용자 설정"이 되고, 다음 곡에서도 그대로다
- [ ] 펼친 칸의 스펙트럼이 소리에 맞춰 움직이고, 멈추면 내려앉는다
- [ ] 접은 줄 오른쪽에 작은 스펙트럼이 움직인다
- [ ] 접은 줄의 "켜짐"을 누르면 꺼지고, "꺼짐"을 누르면 켜진다
- [ ] 접은 줄의 프리셋 이름을 누를 때마다 다음 프리셋으로 바뀌고 소리도 바뀐다
- [ ] 듣는 곳 글자는 눌러도 아무 일이 없다
- [ ] 스펙트럼을 켠 채 30분 들어도 끊김이 없다

## 9. 정한 것

- 프리셋 값과 장르 짝은 우리가 정한 것이다(알송 값을 쓰지 않는다).
- 장르가 없거나 모르면 설정값(자동 전에 쓰던 프리셋), 그것도 없으면 기본(사용자 요청 2026-10-30).
- 라디오 해외 추천은 묶음 장르를 쓴다(제안, 승인됨).
- 자동 중 밴드를 직접 움직이면 자동을 끈다(직접 고친 값을 지키려고).
- 스펙트럼은 들리는 소리 그대로(효과 뒤)이고, 칸이 안 보이면 계산하지 않는다.

# my-fun 1단계 MVP 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 파일·폴더를 열어 재생·일시정지·정지·이전/다음·탐색·볼륨·음소거를 버튼, 단축키, 끌어다 놓기로 쓸 수 있는 PyQt5 플레이어 패널과 혼자 실행 창을 만든다.

**Architecture:** Qt를 쓰지 않는 세 층 위에 PyQt5 `ui/PlayerPanel`을 올린다. 세 층은 `core/`(곡 모으기, 재생목록, 설정), `engine/`(PyAV 디코딩 → 2초 버퍼 → sounddevice 출력), `controller.py`(spec §5 규칙)다. 엔진은 디코딩 스레드가 버퍼를 채우고, 출력 콜백이 버퍼에서 꺼내 쓴다. 엔진 콜백(`on_end`, `on_error`)은 `PlayerBridge`가 Qt 신호로 바꿔 GUI 스레드로 넘긴다.

**Tech Stack:** Python 3.14(3.13 호환), PyQt5 5.15.11, PyAV(`av`) 19.0.2, numpy 2.5.4, sounddevice 0.5.6, pytest 9.1.1

**Spec:** `docs/stage1_design.md` (시안 `docs/images/stage1_mockup.png`, 로드맵 `docs/개발로드맵.md`)

## Global Constraints

- **Python 버전:** 개발은 Python 3.14로 하지만 3.13에서도 돌아야 한다.
  - `funplayer`의 모든 비어 있지 않은 `.py`는 `from __future__ import annotations`로 시작한다.
  - 3.14에서만 되는 문법·모듈(괄호 없는 `except A, B:`, t-string, `annotationlib`)은 쓰지 않는다.
- **의존성:**
  - `requirements.txt`: `PyQt5==5.15.11`, `av==19.0.2`, `numpy==2.5.4`, `sounddevice==0.5.6`
  - `requirements-dev.txt`: `-r requirements.txt`, `pytest==9.1.1`
  - 다른 패키지는 넣지 않는다(pytest-qt, mutagen 포함).
- **Qt 사용 범위:** PySide6는 어디서도 import하지 않는다. `core/`, `engine/`, `controller.py`는 PyQt5를 import하지 않는다.
- **소리 형식:** float32 스테레오 44,100Hz. 출력 블록 2048프레임, 버퍼 2.0초, 디코딩 스레드가 할 일이 없을 때 10ms 쉰다.
- **규칙 상수:**
  - 이전 곡 기준 3.0초
  - 이동 단위 기본 5초(1~100)
  - 볼륨 기본 70(0~100), 실제 크기 `(v/100)**2`
  - 단축키 볼륨 단위 5
  - 화면 갱신 200ms
  - 혼자 실행 창 380×480
- **화면 문구(정확히 이대로):**
  - 메시지: `곡을 추가하세요`, `열 수 없음: {파일명.확장자}`, `소리 장치를 열 수 없습니다`, `재생할 수 있는 파일이 없습니다`

## 계획에서 정한 것 (spec에 없던 결정)

1. "재생 중이 아니었다면"(§5 추가)은 **정지 상태만** 뜻한다. 일시정지 중에 곡을 추가하면 목록에만 붙인다.
2. 정지 상태에서는 탐색이 안 된다. 탐색바를 끄고, ←/→도 무시한다.
3. 볼륨을 바꿔도 음소거는 풀리지 않는다.
4. 열기·추가로 고른 것 중 재생할 수 있는 파일이 하나도 없으면, 목록을 그대로 두고 `재생할 수 있는 파일이 없습니다`를 띄운다. 파일 창에서 취소한 경우에는 아무것도 하지 않는다.
5. 직접 고른 파일도 폴더 안의 파일과 같은 규칙으로 정렬한다(폴더 경로 순서, 그 안에서 자연 정렬).
6. 상태 줄 메시지는 다음 곡 재생을 시작할 때 지운다. 실패한 곡을 건너뛸 때는 메시지를 남긴다.
7. 이전 곡과 "처음부터" 모두 그 곡을 다시 여는 방식(`play_index`)으로 처리한다.
8. 테스트용 WAV는 표준 라이브러리 `wave`로 만든다. MP3만 PyAV로 만든다.
9. 혼자 실행 창은 Fusion 스타일이다(시안과 같다). 처리되지 않은 예외는 `sys.excepthook`으로 로그에 남기고 앱을 끄지 않는다.
10. `AudioPlayer`에 `unload()`, `close()`, `has_track`, `buffered_frames`를 더한다. `unload()`는 비우기 때 파일 잠금을 풀기 위해, 나머지는 테스트를 위해서다.

```python
from funplayer.core.tracks import SUPPORTED_EXTS, expand_paths, natural_key

def touch(p):
    p.parent.mkdir(parents=True, exist_ok=True); p.write_bytes(b"")

def test_supported_exts():
    assert SUPPORTED_EXTS == {".mp3", ".wav", ".flac", ".ogg", ".opus", ".m4a", ".aac", ".wma"}

def test_natural_key():
    names = ["10.mp3", "2.mp3", "track 20.mp3", "1.mp3", "Track 3.mp3"]
    assert sorted(names, key=natural_key) == ["1.mp3", "2.mp3", "10.mp3", "Track 3.mp3", "track 20.mp3"]

def test_folder_recursive_filtered_sorted(tmp_path):
    a = tmp_path / "a"
    for rel in ["10.mp3", "2.MP3", "notes.txt", "cover.jpg", "sub/1.flac", "b/3.ogg"]:
        touch(a / rel)
    assert expand_paths([str(a)]) == [str(a / "2.MP3"), str(a / "10.mp3"),
                                      str(a / "b" / "3.ogg"), str(a / "sub" / "1.flac")]
```

**Files:**

**Interfaces:**
- Produces:
  - `PREV_THRESHOLD = 3.0`
  - `@dataclass Track(path: str, failed: bool = False)`: 속성 `title -> str`(확장자를 뺀 파일 이름)
  - `Playlist`:
    - 상태: `tracks: list[Track]`, `index: int | None`, `version: int`, `__len__`
    - `replace(paths: list[str]) -> None`: 목록이 비어 있지 않으면 `index`를 0으로, 비면 None으로 한다.
    - `add(paths: list[str]) -> int | None`: 새로 붙은 첫 곡의 번호를 돌려준다. `paths`가 비면 None이다. `index`는 바꾸지 않는다.
    - `clear() -> None`
    - `current -> Track | None`
    - `set_current(i: int) -> None`: 범위 밖이면 `IndexError`를 낸다.
    - `next_index() -> int | None`
    - `prev_target(position: float) -> tuple[str, int]`: `index`가 None이 아닐 때만 부른다.
    - `mark_failed(i: int) -> None`
  - `version`은 replace, add, clear, set_current, mark_failed 때마다 1씩 오른다. 화면은 이 값이 바뀌었을 때만 목록을 다시 그린다.

```python
# tests/test_playlist.py
import pytest
from funplayer.core.playlist import Playlist, Track

P = ["C:/m/01 a.mp3", "C:/m/02 b.mp3", "C:/m/03 c.mp3"]

def test_track_title():
    assert Track("C:/m/01 a.mp3").title == "01 a"

def test_replace_and_clear():
    pl = Playlist(); pl.replace(P)
    assert len(pl) == 3 and pl.index == 0 and pl.current.path == P[0]
    pl.replace([]); assert pl.index is None and pl.current is None
    pl.replace(P); pl.clear(); assert len(pl) == 0 and pl.index is None

def test_add_returns_first_new_index_and_keeps_current():
    pl = Playlist()
    assert pl.add(P[:1]) == 0 and pl.index is None
    pl.set_current(0)
    assert pl.add(P[1:]) == 1 and pl.index == 0
    assert pl.add([]) is None

def test_next_index():
    pl = Playlist(); assert pl.next_index() is None
    pl.replace(P); assert pl.next_index() == 1
    pl.set_current(2); assert pl.next_index() is None

@pytest.mark.parametrize("idx,pos,expected", [
    (1, 2.9, ("prev", 0)), (1, 3.0, ("restart", 1)), (0, 1.0, ("restart", 0))])
def test_prev_target(idx, pos, expected):
    pl = Playlist(); pl.replace(P); pl.set_current(idx)
    assert pl.prev_target(pos) == expected

def test_mark_failed_and_version_bumps():
    pl = Playlist(); v = pl.version
    pl.replace(P); pl.set_current(1); pl.mark_failed(2)
    assert pl.tracks[2].failed and not pl.tracks[1].failed
    pl.add(P[:1]); pl.clear()
    assert pl.version == v + 5

def test_set_current_out_of_range():
    pl = Playlist(); pl.replace(P)
    with pytest.raises(IndexError):
        pl.set_current(3)
```

```python
import os, shutil
import numpy as np
import pytest
from funplayer.engine.decoder import SAMPLE_RATE, DecodeError, open_decoder

def drain(dec):
    total = 0
    while (b := dec.read()) is not None:
        assert b.dtype == np.float32 and b.ndim == 2 and b.shape[1] == 2
        total += len(b)
    return total

def test_duration(tone_wav):
    assert abs(open_decoder(tone_wav).duration - 3.0) < 0.05

def test_blocks_total_and_end(tone_wav):
    dec = open_decoder(tone_wav)
    assert abs(drain(dec) - 3 * SAMPLE_RATE) < 0.01 * 3 * SAMPLE_RATE
    assert dec.read() is None and dec.read() is None

def test_mono48k_resampled_to_stereo_44k(mono48k_wav):
    dec = open_decoder(mono48k_wav)
    first = dec.read()
    assert np.allclose(first[:, 0], first[:, 1])
    assert abs(len(first) + drain(dec) - 3 * SAMPLE_RATE) < 0.01 * 3 * SAMPLE_RATE

def test_seek_accuracy(tone_wav):

    assert abs(dec.read()[0, 1] / 0.3 - 1.5) < 0.05
```

- [ ] **Step 4: `funplayer/engine/decoder.py` 구현**

- **열기:**
  - `av.open(path, metadata_errors="replace")`로 연다. 태그 글자가 깨져도 열리게 하기 위해서다.
  - `container.streams.audio[0]`을 쓴다. 없으면 `DecodeError`다.
  - `AudioResampler(format="flt", layout="stereo", rate=44100)`를 만든다. 출력은 `frame.to_ndarray().reshape(-1, 2)`다.
- **길이:** `container.duration / 1_000_000`을 쓰고, 없으면 `stream.duration * stream.time_base`, 그것도 없으면 0.0이다.
- **첫 블록:** `open_decoder` 안에서 첫 블록을 미리 읽어 둔다. 그래야 열리기는 하지만 풀리지 않는 파일을 여는 단계에서 걸러낸다. 첫 블록이 None이면 `DecodeError`이고, 미리 읽은 블록은 첫 `read()`가 돌려준다.
- **끝:** 디코드가 끝나면 `resampler.resample(None)`으로 남은 샘플을 한 번 비워 낸다.
- **이동:**
  - `container.seek(int(sec / stream.time_base), stream=stream)`으로 이동한다. 이동한 뒤에는 resampler와 디코드 반복자를 새로 만든다.
  - 목표 시각까지 맞추는 법:
    - 끝 시각(`frame.time + frame.samples / frame.sample_rate`)이 목표 이하인 프레임은 통째로 버린다.
    - 목표에 걸친 첫 프레임은 리샘플 결과에서 앞쪽 `round((sec - frame.time) * 44100)`프레임을 잘라낸다.
    - `frame.time`이 None이면 자르지 않는다.
  - 이동하면 미리 읽어 둔 블록과 끝 표시를 버린다.
  - 이동 중 PyAV 오류가 나면 끝에 닿은 것으로 처리한다.

### Task 5: 출력과 재생 엔진 (Sink, AudioPlayer)

**Files:**
- Create: `funplayer/engine/sink.py`, `funplayer/engine/player.py`
- Test: `tests/test_player.py`

**Interfaces:**
- Consumes: `open_decoder`, `DecodeError`, `SAMPLE_RATE` (Task 4), `read_frames` (conftest)
- Produces from `sink.py`:
  - `class SinkError(Exception)`
  - `SoundDeviceSink(callback, samplerate=44100, channels=2, blocksize=2048)`: 메서드 `start()`, `stop()`, `close()`
    - `callback(outdata: np.ndarray) -> None`은 `(frames, 2)` float32 배열을 그 자리에서 채운다.
    - `sounddevice`는 `__init__` 안에서 import한다.
    - import 실패, `sd.PortAudioError`, `OSError`는 모두 `SinkError`로 바꾼다.
  - `FakeSink(callback, fail_on_start=False)`:
    - 속성 `started: bool`, `closed: bool`, 메서드 `start()`, `stop()`, `close()`
    - `start()`: `fail_on_start`이면 `SinkError`를 낸다.
    - `pull(frames=2048) -> np.ndarray`: 0으로 채운 배열로 콜백을 부르고 그 배열을 돌려준다. `started`가 아니면 `AssertionError`다.
- Produces from `player.py`:
  - `class State(Enum)`: `STOPPED`, `PLAYING`, `PAUSED`
  - `DEVICE_ERROR_MSG = "소리 장치를 열 수 없습니다"`
  - `AudioPlayer(sink_factory=SoundDeviceSink, open_decoder=open_decoder, threaded=True, buffer_seconds=2.0)`
    - 콜백 속성: `on_end: Callable[[], None] | None`, `on_error: Callable[[str], None] | None`
    - 읽기 전용: `state`, `position: float`, `duration: float`, `has_track: bool`, `buffered_frames: int`
    - 메서드: `load(path)`, `unload()`, `play()`, `pause()`, `stop()`, `seek(sec)`, `set_gain(g)`, `pump() -> bool`, `close()`

**동작 (이 표가 구현 기준이다):**

| 호출 | 동작 |
|---|---|
| `load(path)` | 출력을 멈추고, 이전 디코더를 닫고, 버퍼·기준점·센 프레임·끝 표시를 비운다. 상태는 STOPPED다. 그다음 연다. `DecodeError`가 나면 그대로 내보내고, `has_track`은 False로 남는다. |
| `unload()` | `load`의 앞부분만 한다(닫고 비운다). `duration`은 0이 된다. |
| `play()` | 곡이 없거나 이미 PLAYING이면 아무것도 하지 않는다. 출력이 없으면 `sink_factory(self._callback)`로 만든 뒤 `start()`한다. `SinkError`가 나면 출력을 버리고(다음 재생에서 새로 만든다) STOPPED로 두고, 잠금을 놓은 뒤 `on_error(DEVICE_ERROR_MSG)`를 부른다. |
| `pause()` | PLAYING일 때만 한다. 출력을 `stop()`하고 PAUSED로 바꾼다. 버퍼는 그대로 둔다. |
| `stop()` | 출력을 멈추고, 버퍼를 비우고, 디코더를 0으로 돌린다. 기준점 0, 센 프레임 0, 상태 STOPPED다. |
| `seek(sec)` | 곡이 없으면 아무것도 하지 않는다. 0 이상으로 자르고, 길이를 알면 길이 이하로 자른다. 버퍼를 비우고 `decoder.seek`한 뒤 기준점을 sec으로, 센 프레임을 0으로 하고 끝 표시를 지운다. 상태는 그대로다. |
| `pump()` | 디코딩 한 단계다. 곡이 있고, 끝이 아니고, 버퍼가 목표(`buffer_seconds*44100`)보다 적으면 `read()` 한 번을 버퍼에 붙인다. `read()`가 None이거나 예외를 내면 끝 표시를 한다. 예외면 `logger.warning`도 남긴다. PLAYING이고 끝이고 버퍼가 비었으면, `stop()`과 같은 처리를 한 뒤 잠금을 놓고 `on_end()`를 **한 번만** 부른다. 일을 했으면 True를 돌려준다. |
| 출력 콜백 | `_buf_lock` 안에서 버퍼의 프레임을 `outdata`로 옮기고, 모자라는 부분은 0으로 채운 뒤 gain을 곱한다. 실제로 옮긴 프레임만 센다. |
| `position` | 기준점 + 센 프레임 ÷ 44,100 |
| `close()` | 스레드를 멈추고(join, 시간 제한 1초) 출력과 디코더를 닫는다. 여러 번 불러도 된다. |

**잠금:** `_lock`(RLock)은 디코더, 상태, 출력을 지키고 `_buf_lock`은 버퍼와 센 프레임을 지킨다. `pump()`는 `read()`부터 버퍼에 붙일 때까지 `_lock`을 쥐고 있다. 그래야 이동 직전에 읽은 블록이 이동 뒤 버퍼에 들어가지 않는다.

**스레드:** `threaded=True`이면 daemon 스레드가 `pump()`를 되풀이한다. 할 일이 없으면 종료 이벤트를 10ms 기다린다. 반복 본문의 예외는 `logger.exception`으로 남기고 계속 돈다.

**규칙:**

| 메서드 | 동작 |
|---|---|
| `play_index(i)` | `status=""`로 시작한다. 그 곡을 `set_current` → `load` → `play`한다. `DecodeError`가 나면 `mark_failed`하고 `status=FAIL_MSG.format(name=파일명.확장자)`로 바꾼 뒤 `next_index()`로 계속한다. 시도는 목록 길이만큼만 한다. 더 갈 곳이 없으면 `player.stop()`한다. |
| `open(paths)` | `expand_paths` 결과가 비면 `status=NO_FILES_MSG`로 하고 끝낸다. 아니면 `player.stop()` → `replace` → `play_index(0)` |
| `add(paths)` | 결과가 비면 `NO_FILES_MSG`. 아니면 `add`하고, 플레이어가 STOPPED였을 때만 `play_index(첫 새 곡)` |
| `toggle()` | PLAYING이면 pause, PAUSED면 play, STOPPED면 `play_index(현재)`. 목록이 비면 아무것도 하지 않는다. |
| `next()` / `on_track_end()` | `next_index()`가 있으면 `play_index`, 없으면 `player.stop()` |
| `prev()` | 현재 곡이 있을 때 `prev_target(position)`의 번호로 `play_index` |
| `seek_by(d)` | STOPPED면 무시한다. 목표 = position + d·seek_step이고, 0보다 작으면 0이다. 길이 > 0이고 목표 ≥ 길이면 `next()`, 아니면 `player.seek(목표)` |
| `seek_to(sec)` | STOPPED면 무시한다. `[0, duration]`으로 자른 뒤 `player.seek` |
| `set_volume(v)` / `toggle_mute()` | 설정에 저장하고 gain을 다시 적용한다: 음소거면 0.0, 아니면 `(volume/100)**2` |
| `clear()` | `player.stop()` → `player.unload()` → `playlist.clear()`, `status=""` |
| `on_player_error(msg)` | `status=msg` |
| `title` | 현재 곡의 `Track.title`. 목록이 비면 `EMPTY_TITLE` |

```python
def wait_for(cond, timeout=1.0):
    end = time.monotonic() + timeout
    while not cond() and time.monotonic() < end:
```

### Task 8: 화면 입력 (버튼, 슬라이더, 목록, 메뉴, 단축키, 끌어다 놓기)

**Files:**
- Modify: `funplayer/ui/jump_slider.py`, `funplayer/ui/player_panel.py`

**Interfaces:**
- Consumes: `PlayerPanel` 위젯 이름들(Task 7), `PlayerController` 메서드(Task 6), `SUPPORTED_EXTS`(Task 1)
- Produces:
  - `JumpSlider.mousePressEvent`:
    - 왼쪽 버튼이면 클릭한 x 위치를 `QStyle.sliderValueFromPosition`으로 값으로 바꿔 `setValue`한다. 핸들 폭은 `style().subControlRect(...SC_SliderHandle...)`로 구한다.
    - 그다음 `super().mousePressEvent`를 부른다. 클릭 위치에 이미 핸들이 와 있으므로 바로 끌기가 이어진다.
  - `SHORTCUTS: list[tuple[str, str]]`:
    ```
    [("Space","toggle"), ("X","toggle"), ("V","stop"), ("Z","prev"), ("B","next"),
     ("Left","seek_back"), ("Right","seek_forward"), ("Up","volume_up"), ("Down","volume_down"),
     ("M","toggle_mute"), ("L","open_files")]
    ```
  - `PlayerPanel.shortcuts: dict[str, QShortcut]`: 키는 위 표의 키 글자이고, context는 `Qt.WidgetWithChildrenShortcut`이다.
  - `PlayerPanel` 동작 메서드(단축키와 메뉴가 이름으로 부른다): `toggle`, `stop`, `prev`, `next`, `seek_back`, `seek_forward`, `volume_up`, `volume_down`, `toggle_mute`, `open_files`, `open_folder`, `add_files`, `add_folder`
    - 각각 컨트롤러를 부른 뒤 `refresh()`한다.
    - 볼륨은 ±5다.
    - `open_*`/`add_*`는 고른 경로가 비어 있으면 아무것도 하지 않는다.
  - `ask_files() -> list[str]`: `QFileDialog.getOpenFileNames`를 연다.
    - 창 제목은 `파일 열기`다.
    - 필터는 `"음악 파일 (" + " ".join("*" + e for e in sorted(SUPPORTED_EXTS)) + ")"`
  - `ask_folder() -> list[str]`: `QFileDialog.getExistingDirectory`를 연다. 창 제목은 `폴더 선택`이고, 취소하면 `[]`다.

**연결:**
- **버튼:**
  - 이전/재생/정지/다음/음소거 → 같은 이름의 동작 메서드
  - `clear_button` → `controller.clear()` + `refresh()`
  - `open_button`과 `add_button`에는 QMenu를 붙인다. 메뉴 항목은 `파일…`, `폴더…`이고 각각 `open_files`/`open_folder`, `add_files`/`add_folder`를 부른다.
- **슬라이더와 목록:**
  - `volume_slider.valueChanged` → `controller.set_volume`
  - `seek_slider`:
    - `sliderPressed`: `_dragging = True`
    - `sliderMoved(v)`: `elapsed_label`만 `format_time(v/1000)`으로 바꾼다.
    - `sliderReleased`: `controller.seek_to(value/1000)`, `_dragging = False`
  - `playlist_view.itemDoubleClicked` → `controller.play_index(row)`
- **끌어다 놓기:**
  - `setAcceptDrops(True)`
  - `dragEnterEvent`: URL 중 로컬 파일이 하나라도 있으면 받는다.
  - `dropEvent`: 로컬 경로들로 `controller.add`를 부르고 `refresh()`한다.

```python
# tests/test_main.py
import logging, sys
from logging.handlers import RotatingFileHandler
from PyQt5.QtCore import QTimer
from PyQt5.QtWidgets import QApplication
import funplayer.__main__ as entry

def _cleanup():
    lg = logging.getLogger("funplayer")
    for h in list(lg.handlers):
        h.close(); lg.removeHandler(h)

def test_app_dir(monkeypatch, tmp_path):
    monkeypatch.setenv("APPDATA", str(tmp_path))
    assert entry.app_dir() == tmp_path / "my-fun"

def test_setup_logging(tmp_path):
    try:
        entry.setup_logging(tmp_path / "logs"); entry.setup_logging(tmp_path / "logs")
        files = [h for h in logging.getLogger("funplayer").handlers if isinstance(h, RotatingFileHandler)]
        assert len(files) == 1 and files[0].maxBytes == 1_000_000 and files[0].backupCount == 2
        assert files[0].baseFilename.endswith("funplayer.log")
    finally:
        _cleanup()

def test_main_smoke(qapp, monkeypatch, tmp_path):
    monkeypatch.setenv("APPDATA", str(tmp_path))
    monkeypatch.setattr(sys, "excepthook", sys.excepthook)
    QTimer.singleShot(0, QApplication.instance().quit)
    try:
        assert entry.main([]) == 0
        assert (tmp_path / "my-fun" / "logs" / "funplayer.log").exists()
    finally:
        _cleanup()
```

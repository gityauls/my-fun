## 1. 범위

**만드는 것:**
- B-7 반복 재생 (끄기 / 전체 / 한 곡)
- B-8 무작위 재생
- C-5 재생목록 저장·불러오기 (m3u8)
- C-6 목록 편집: 고른 곡 지우기, 중복 곡 지우기, 없는·깨진 파일 지우기, 정렬, 전체 선택
- 목록에서 곡을 끌어서 순서 바꾸기 (시안 승인 때 사용자 요청으로 추가)
- J-1 이 기능들의 단축키
- 1단계에서 미룬 것:
  - Enter로 고른 곡 재생
  - 탐색바 손잡이 클릭 테스트 보강

**이번에 빼는 것:**
- 폴더 반복. 알송에는 있지만 로드맵에서 고르지 않았다.
- 목록 검색(C-4), 폴더 보기(C-3)
- 끌 때 목록과 위치 기억 → 2-B (K-2)

## 2. 화면

시안: `docs/images/stage2a_mockup.png`

```
┌ my-fun ─────────────────────────────────┐
│ 곡 제목                                   │
│ 01:12 ━━━━━━●──────────────────── 03:45 │
│ [⏮] [⏸] [■] [⏭]  [🔁] [🔀]   [🔊] ━━●── │  ← 반복·무작위 단추 추가
├─────────────────────────────────────────┤
│  1  봄날의 산책                           │
│ ▶2  Morning Coffee        (굵게)          │
│  4  비 오는 오후           (선택됨)        │  ← 여러 줄 선택
├─────────────────────────────────────────┤
│ [열기 ▾] [추가 ▾] [목록 ▾]           6곡 │  ← [비우기]는 [목록 ▾] 안으로
│ 중복 곡 2개를 지웠습니다     (안내는 회색) │
└─────────────────────────────────────────┘
```

- **반복 단추:**
  - 누를 때마다 끔 → 전체 → 한 곡 → 끔으로 바뀐다.
  - 끔이면 회색이고, 전체면 강조색에 눌린 모양이다. 한 곡이면 거기에 "1"이 붙는다.
  - 풍선 도움말에 "반복: 끔/전체/한 곡"을 보여준다.
- **무작위 단추:** 켜고 끈다. 켜면 강조색에 눌린 모양이다. 풍선 도움말은 "무작위: 끔/켬"이다.
- **아이콘:** Qt 기본 아이콘에는 반복·무작위 모양이 없다. 그래서 `ui/icons.py`에서 선으로 직접 그린다. 5.5단계에서 다듬는다.
- **[열기 ▾] / [추가 ▾]:** 1단계의 "파일…", "폴더…"에 "재생목록…"을 더한다. 열기는 목록을 바꾸고, 추가는 목록 끝에 붙인다.
- **[목록 ▾]** (1단계의 [비우기] 단추 자리):
  - 재생목록 저장… (사용자 확인 뒤 "저장…"에서 바꿈: 이름만 보고는 찾기 어려웠다)
  - 선택한 곡 지우기
  - 중복 곡 지우기
  - 없는·깨진 파일 지우기
  - 정렬 ▸ (이름순 / 폴더·이름순)
  - 목록 비우기
  - [비우기]를 메뉴 안으로 옮기는 이유: 아래 줄에 단추 넷과 곡 수를 놓기에는 380px 폭이 좁다.
- **목록:**
  - Ctrl·Shift+클릭으로 여러 줄을 고른다.
  - 오른쪽 클릭 메뉴에는 재생, 선택한 곡 지우기, 전체 선택이 있다.
  - 곡이 바뀌어도 골라 둔 줄은 풀리지 않는다. 1단계는 곡이 바뀔 때마다 목록을 다시 만들어서 선택이 풀렸다.
  - 지금 곡 표시와 회색 표시만 바뀔 때는 해당 줄만 고친다.
  - 목록 내용이 바뀔 때(추가, 지우기, 정렬)만 목록을 다시 만든다.
  - 고른 곡을 지운 뒤에는 지운 자리의 줄을 골라 둔다. Del을 연달아 누를 수 있게 하기 위해서다.
  - 고른 줄을 끌어서 다른 자리에 놓으면 순서가 바뀐다. 놓을 자리에는 가로선이 보인다.
- **메뉴의 단축키 표시:** 메뉴 오른쪽에 키 이름만 적는다. 실제 키는 §3의 단축키가 처리한다.
- **상태 줄:** 오류는 1단계처럼 빨강(#B3261E)으로, 안내는 회색(#5F6368)으로 보여준다.

## 3. 단축키

1단계 키는 그대로 둔다. 플레이어에 포커스가 있을 때만 동작하는 것도 같다.

| 키 | 동작 |
|---|---|
| R | 반복 바꾸기 (끔 → 전체 → 한 곡) |
| S | 무작위 켜기/끄기 |
| Ctrl+S | 재생목록 저장 |
| Ctrl+O | 재생목록 열기 (목록 바꾸기) |
| Del | 선택한 곡 지우기 |
| Enter | 목록에서 고른 곡 재생 |
| Ctrl+A | 전체 선택 |

## 4. 동작 규칙

### 4.1 반복 (B-7)

- **끔:** 1단계와 같다. 마지막 곡이 끝나면 정지한다.
- **전체:**
  - 마지막 곡 다음은 첫 곡이다. 곡이 저절로 끝날 때와 [다음]을 누를 때 모두 그렇다.
  - 순서대로 재생할 때, 첫 곡에서 [이전]을 누르면(3초 미만) 마지막 곡으로 간다.
- **한 곡:**
  - 곡이 저절로 끝나면 같은 곡을 처음부터 다시 재생한다.
  - [다음], [이전], 곡 끝을 넘는 → 이동은 평소처럼 움직인다. 이때 다음 곡의 기준은 "전체"와 같다.
  - 다시 열 수 없는 곡이면 평소처럼 건너뛴다.
- **저장:** `player_repeat` (`"off"` / `"all"` / `"one"`, 기본 `"off"`). 바꿀 때마다 저장한다.

### 4.2 무작위 (B-8)

- **켜면:**
  - 목록의 모든 곡을 한 번씩 섞은 "재생 순서"를 만든다.
  - 지금 곡이 있으면 순서의 맨 앞에 두고, 그 곡은 끊기지 않는다.
  - 한 바퀴 동안 같은 곡은 다시 나오지 않는다.
- **끄면:** 지금 곡부터 목록 순서대로 이어 간다.
- **한 바퀴가 끝나면:**
  - 반복이 끔이면 정지한다.
  - 반복이 전체·한 곡이면 새로 섞어서 계속한다.
- **[이전] (3초 미만):** 재생 순서에서 바로 앞에 들은 곡으로 간다. 순서의 첫 곡이면 처음부터 다시 재생한다.
- **곡을 직접 고르면(더블클릭, Enter):**
  - 그 곡을 지금 곡 바로 다음 순서로 옮기고 재생한다.
  - 나머지 순서는 그대로다. 그래서 [이전]을 누르면 고르기 전에 듣던 곡으로 돌아간다.
- **열기:** 섞은 순서의 첫 곡부터 재생한다.
- **추가:** 새 곡을 아직 안 들은 순서 사이사이에 무작위로 끼워 넣는다. 정지 상태에서 추가하면 1단계 규칙대로 재생을 시작한다. 이때 첫 곡은 추가한 곡 중 순서가 가장 빠른 곡이다.
- **목록 번호:** 목록에 보이는 번호와 정렬은 바뀌지 않는다. 재생 순서만 섞인다.
- **저장:** `player_shuffle` (기본 false). 바꿀 때마다 저장한다.
- **테스트:** 섞는 데 쓰는 난수 발생기를 바꿔 끼울 수 있게 해서, 테스트에서는 결과가 고정되게 한다.

### 4.3 재생목록 저장·불러오기 (C-5)

- **형식:** m3u8. 첫 줄은 `#EXTM3U`이고, 다음 줄부터 한 줄에 곡 하나씩 쓴다. UTF-8(BOM 없음)로, 줄바꿈은 CRLF로 쓴다.
- **경로:**
  - 재생목록 파일이 있는 폴더(하위 폴더 포함) 안의 곡은 상대 경로로 쓴다.
  - 그 밖의 곡은 절대 경로로 쓴다.
  - 이렇게 하면 음악 폴더 안에 저장한 목록은 폴더째 옮겨도 계속 쓸 수 있다.
- **저장 (Ctrl+S, [목록 ▾] → 재생목록 저장…):**
  - 저장 대화상자에서 고른 이름에 확장자가 없으면 `.m3u8`을 붙인다.
  - 목록이 비어 있으면 저장 메뉴를 끈다.
  - 성공하면 "저장했습니다: 이름"을 안내로, 실패하면 "저장할 수 없음: 이름"을 오류로 보여준다.
- **불러오기 ([열기 ▾]/[추가 ▾] → 재생목록…, Ctrl+O는 열기):**
  - `.m3u8`과 `.m3u`를 읽는다.
  - `.m3u8`은 UTF-8로 읽는다(BOM이 있어도 된다). `.m3u`는 UTF-8로 읽어 보고, 안 되면 CP949로 읽는다. 다른 Windows 플레이어가 만든 한글 목록 때문이다.
  - `#`으로 시작하는 줄과 빈 줄은 건너뛴다. `file:///` 주소는 파일 경로로 바꾼다.
  - 상대 경로는 재생목록 파일의 폴더를 기준으로 푼다.
  - 지원하지 않는 확장자와 `http://` 같은 인터넷 주소는 건너뛴다. 인터넷 주소는 3단계(라디오)에서 다룬다.
  - **파일 순서 그대로 넣는다.** 폴더 열기와 달리 정렬하지 않는다.
  - 없는 파일도 목록에 넣고 회색으로 보여준다. 그리고 "없는 파일 N곡"을 안내한다.
  - 열기와 추가의 나머지 규칙(재생 시작 등)은 1단계와 같다.
  - 읽을 수 없는 파일이면 "불러올 수 없음: 이름"을 오류로, 곡이 하나도 없으면 1단계의 "재생할 수 있는 파일이 없습니다"를 보여준다.
- **끌어다 놓기:** `.m3u8`·`.m3u` 파일을 놓으면 그 안의 곡을 추가한다. 음악 파일과 섞어 놓으면 음악 파일을 먼저(1단계 정렬대로), 재생목록의 곡을 그 뒤에(파일 순서대로) 붙인다.
- **폴더 안의 재생목록 파일:** 폴더를 열거나 추가할 때는 그 안의 `.m3u` 파일을 읽지 않는다. 같은 곡이 두 번 들어가는 것을 막기 위해서다.

### 4.4 목록 편집 (C-6)

- **선택한 곡 지우기 (Del):**
  - 목록에서만 빼고, 파일은 지우지 않는다.
  - 지금 곡을 지우면 남은 곡 중에서 [다음]을 눌렀을 때 갈 곡이 지금 곡이 된다. 순서대로면 지운 자리의 다음 줄이고, 무작위면 재생 순서의 다음 곡이다.
  - 그런 곡이 없으면(목록 끝이고 반복 끔) 재생 순서에서 바로 앞의 남은 곡이 지금 곡이 되고, 정지한다.
  - 재생 중이었다면 새 지금 곡을 이어서 재생한다. 일시정지나 정지 상태였다면 정지 상태로 둔다.
  - 모든 곡을 지우면 [목록 비우기]와 같다.
- **중복 곡 지우기:**
  - 경로가 같은 곡(대소문자 무시)은 하나만 남긴다.
  - 지금 곡이 중복이면 지금 곡을 남기고, 아니면 맨 앞의 것을 남긴다.
  - "중복 곡 N개를 지웠습니다" 또는 "중복 곡이 없습니다"를 안내한다.
- **없는·깨진 파일 지우기:**
  - 파일이 없어진 곡과 회색(열 수 없었던) 곡을 뺀다.
  - 지금 곡이 빠지면 "선택한 곡 지우기"의 규칙을 따른다.
  - "N곡을 지웠습니다" 또는 "지울 곡이 없습니다"를 안내한다.
- **정렬:**
  - 이름순은 파일 이름을 자연 정렬한다.
  - 폴더·이름순은 1단계의 폴더 추가 순서와 같다.
  - 지금 곡과 재생은 그대로 이어진다. 순서대로 재생 중이면 다음 곡은 새 순서를 따른다.
- **끌어서 순서 바꾸기:**
  - 고른 줄(여러 줄도 된다)을 끌어서 줄 사이에 놓으면 그 자리로 옮긴다. 옮긴 줄끼리의 순서는 그대로다.
  - 옮긴 뒤에도 그 줄들을 계속 골라 둔다.
  - 지금 곡과 재생은 그대로 이어진다. 순서대로 재생 중이면 다음 곡은 새 순서를 따른다. 무작위면 재생 순서는 바뀌지 않는다.
  - 탐색기에서 파일을 목록 위에 끌어다 놓으면 1단계처럼 목록 끝에 추가한다.
- **전체 선택 (Ctrl+A, 오른쪽 클릭):** 목록의 모든 줄을 고른다.
- **Enter:** 목록에서 포커스가 있는 줄을 재생한다(더블클릭과 같다).
- **무작위와 함께 쓸 때:** 지우거나 정렬하거나 옮겨도 남은 곡의 재생 순서는 그대로 유지한다.

### 4.5 상태 줄

- 1단계처럼 다음 곡 재생이 시작될 때 지운다.
- 오류: "열 수 없음: …", "저장할 수 없음: …", "불러올 수 없음: …", "소리 장치를 열 수 없습니다", "재생할 수 있는 파일이 없습니다"
- 안내: "저장했습니다: …", "없는 파일 N곡", "중복 곡 N개를 지웠습니다", "중복 곡이 없습니다", "N곡을 지웠습니다", "지울 곡이 없습니다"

## 5. 구조와 인터페이스

```
funplayer/
├─ core/
│  ├─ order.py      PlayOrder: 순서대로/무작위 재생 순서와 현재 위치 (새 파일)
│  ├─ playlist.py   Playlist: 지우기·중복·없는 파일·정렬, 순서 번호 맞추기 (확장)
│  ├─ m3u.py        read_playlist(path) -> list[str], write_playlist(path, paths) (새 파일)
│  └─ settings.py   repeat, shuffle 추가
├─ controller.py    반복·무작위 규칙, 재생목록 열기·추가·저장, 편집, 상태 종류
└─ ui/
   ├─ icons.py      repeat_icon(mode, color), shuffle_icon(color) (새 파일)
   ├─ playlist_view.py  PlaylistView: 여러 줄 선택, 끌어서 옮기기, 파일 놓기 (새 파일)
   └─ player_panel.py  단추·메뉴·오른쪽 클릭·단축키, 선택을 지키는 목록 갱신
```

- **`PlayOrder`** (화면 없음):
  - 무작위가 꺼져 있으면 목록 순서이고, 켜져 있으면 섞은 순서다.
  - 다음 곡과 이전 곡 번호를 알려 주고, 직접 고른 곡을 순서에 반영한다.
  - 곡이 지워지거나 정렬되면 번호를 다시 맞춘다.
  - 난수 발생기(`random.Random`)를 넘겨받는다.
- **`Playlist`:**
  - 1단계의 `next_index()`, `prev_target()`는 반복 전체 여부(`wrap`)를 받게 바꾼다.
  - 편집 함수를 더한다: `remove(indices)`, 중복·재생할 수 없는 곡 찾기, `sort(by)`, `move(rows, before)`.
  - 구조가 바뀔 때 오르는 `version`과, 지금 곡·회색 표시가 바뀔 때 오르는 번호를 따로 둔다. 화면이 줄만 고칠지, 목록을 다시 만들지 고르는 데 쓴다.
- **`m3u`:** 파일 읽기·쓰기와 경로 변환만 한다. 재생목록 규칙은 컨트롤러가 정한다.
- **`PlayerController`:**
  - 더하는 것: `repeat`, `shuffle`, `cycle_repeat()`, `toggle_shuffle()`, `save_playlist(path)`, `remove(indices)`, `remove_duplicates()`, `remove_unplayable()`, `sort(by)`, `move(rows, before)`, `status_error`
  - 1단계의 `open(paths)`와 `add(paths)`가 재생목록 파일(`.m3u8`·`.m3u`)도 받는다. 대화상자와 끌어다 놓기가 같은 길을 쓴다.
  - `on_track_end()`의 "정지 상태일 때만 받는다" 규칙(1단계)은 그대로 둔다.
- **`Settings`:**
  - `player_repeat` (`"off"`). 다른 값이면 `"off"`로 본다.
  - `player_shuffle` (false). bool이 아니면 false로 본다.
- **화면에는 규칙을 넣지 않는다.** 1단계와 같다.

## 6. 테스트

- **order (난수 고정):**
  - 순서대로: 다음, 끝, 전체 반복 시 처음으로
  - 무작위: 한 바퀴에 모든 곡이 한 번씩 나오는지, 켤 때 지금 곡이 맨 앞인지
  - 무작위 이전: 직전 곡으로 가는지
  - 직접 고르기: 고른 곡이 다음 순서로 가는지
  - 한 바퀴 뒤 다시 섞기
  - 지우기·정렬 후 번호 맞추기
- **playlist:** 지우기(지금 곡 앞·뒤·자신·전부), 중복(지금 곡 우선), 없는·깨진 파일, 두 가지 정렬과 지금 곡 유지, 두 version 번호
- **m3u:**
  - 저장 → 불러오기 왕복이 같은 경로·순서를 돌려주는지 (한글 이름 포함)
  - 상대·절대 경로를 고르는 규칙
  - BOM, CP949 `.m3u`, 주석·빈 줄, `file:///`, 인터넷 주소 건너뛰기
  - 없는 파일은 그대로 돌려주는지
- **settings:** 새 키 기본값과 잘못된 값 처리
- **controller (가짜 플레이어):**
  - §4 규칙 하나씩: 한 곡 반복, 전체 반복의 다음·이전, 무작위 한 바퀴 끝, 지금 곡 지우기
  - 재생목록 열기·추가·저장과 상태 메시지 종류
  - 늦게 온 곡 끝 알림 무시(1단계 규칙)가 반복과 함께 유지되는지
- **panel (offscreen):**
  - 반복·무작위 단추의 모양과 풍선 도움말
  - 메뉴 항목과 새 단축키가 컨트롤러를 부르는지
  - 곡이 바뀌어도 선택이 유지되는지
  - 지운 뒤 그 자리 줄을 고르는지
  - 줄을 끌어 놓으면 순서가 바뀌고 옮긴 줄이 골라져 있는지, 파일을 목록에 놓으면 추가되는지
  - 상태 줄 색
  - 손잡이 클릭 테스트 보강(1단계에서 미룬 것)

## 7. 완료 기준 (사용자 체크리스트)

- [ ] 반복 단추와 R 키로 끔 → 전체 → 한 곡이 바뀌고, 껐다 켜도 기억된다
- [ ] 한 곡 반복: 곡이 끝나면 같은 곡이 처음부터 다시 나온다
- [ ] 전체 반복: 마지막 곡이 끝나면 첫 곡으로 넘어간다
- [ ] 무작위(단추, S 키): 섞인 순서로 나오고, 한 바퀴 동안 같은 곡이 다시 나오지 않는다
- [ ] 무작위에서 Z(이전)를 누르면 방금 들은 곡으로 돌아간다
- [ ] 목록을 저장(Ctrl+S)하고 비운 뒤 다시 열면(Ctrl+O) 같은 곡이 같은 순서로 돌아온다
- [ ] 저장한 `.m3u8`을 창에 끌어다 놓으면 곡이 추가된다
- [ ] 여러 곡을 골라 Del로 지울 수 있고, 듣던 곡을 지우면 다음 곡이 이어서 나온다
- [ ] 중복 곡 지우기, 없는·깨진 파일 지우기, 정렬 두 가지가 된다
- [ ] 곡이 바뀌어도 골라 둔 줄이 풀리지 않고, Enter로 고른 곡이 재생된다
- [ ] 줄을 끌어서 순서를 바꿀 수 있고, 듣던 곡은 끊기지 않는다

## 8. 정한 것 (결정 기록)

- 반복 단추 하나로 끔 → 전체 → 한 곡을 돌린다. 폴더 반복은 넣지 않는다.
- 한 곡 반복은 곡이 저절로 끝날 때만 적용한다. 단추와 키로 옮기는 동작은 평소대로다.
- 순서대로 재생 + 전체 반복이면 첫 곡에서 [이전]을 눌렀을 때 마지막 곡으로 간다. 무작위에서는 처음부터 다시 재생한다.
- 무작위는 한 바퀴에 한 번씩 나오는 방식으로 한다. 켤 때 지금 곡은 끊지 않는다.
- 무작위에서 직접 고른 곡은 다음 순서로 끼워 넣는다.
- 반복·무작위 상태는 저장해서 다음 실행에도 쓴다.
- 재생목록은 m3u8(UTF-8)로 쓴다. 목록 폴더 안의 곡만 상대 경로로 쓴다.
- `.m3u`는 UTF-8 → CP949 순서로 읽는다.
- 불러온 목록은 정렬하지 않는다. 없는 파일은 회색으로 남긴다.
- 지금 곡을 지우면 [다음]으로 갈 곡으로 넘어가고, 재생 중이었으면 이어서 재생한다.
- "없는·깨진 파일 지우기"는 없어진 파일과 회색 곡을 함께 뺀다.
- 정렬은 이름순과 폴더·이름순 두 가지다.
- 끌어서 순서 바꾸기를 넣는다(사용자 요청). 옮겨도 듣던 곡은 끊기지 않는다.
- [비우기] 단추는 [목록 ▾] 메뉴의 "목록 비우기"로 옮긴다.
- 상태 줄은 오류는 빨강, 안내는 회색으로 보여준다.
- 반복·무작위 아이콘은 직접 그린 선 아이콘으로 하고, 5.5단계에서 다듬는다.

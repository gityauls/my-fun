# 5-B 즐겨찾기 설계

> 사용자 지정(2026-10-31) + 시안 확인 뒤 바꾼 것(2026-11-01). 시안: `docs/images/stage5b_mockup.png`.

## 1. 동작

| 할 일 | 결과 |
|---|---|
| 우클릭 "즐겨찾기 (맨 위로)" 또는 Ctrl+D | 고른 곡이 재생목록 맨 위 즐겨찾기 묶음의 끝으로 가고, 제목이 파란 글(`FAVORITE_COLOR`)이 된다 |
| 우클릭 "즐겨찾기 해제" 또는 Ctrl+D | 검은 글로 돌아오고, 나머지 곡 사이 **이름순 자리**(숫자 → 영문 → 가나다, `name_sort_key`)로 간다 |
| 여러 곡을 골랐을 때 | 모두 즐겨찾기면 모두 해제, 하나라도 아니면 모두 넣기 |
| 목록 ▸ 즐겨찾기 저장… | 즐겨찾기한 곡 전부(목록에 없는 곡 포함)를 즐겨찾기 순서대로 .m3u8로 저장 |
| 목록 ▸ 즐겨찾기 불러오기… | 파일의 곡을 즐겨찾기에 더하고, 재생목록에 없는 곡은 덧붙인 뒤 맨 위 묶음으로 모은다. 기존 즐겨찾기는 지우지 않는다 |

## 2. 규칙

- 즐겨찾기는 설정 `player_favorites`에 파일 경로로, 즐겨찾기한 순서대로 기억한다. 대소문자·상대 경로는 같은 파일로 본다(`path_key`).
- 목록을 열기·더하기·정렬·끌어 옮기기·다시 켜기 할 때마다 `Playlist.arrange`가 즐겨찾기 묶음을 맨 위에 다시 모은다. 정렬은 나머지 곡에만 적용된다.
- `arrange`는 줄 순서만 바꾸고 지금 곡 번호를 따라 옮긴다. 재생 엔진은 건드리지 않으므로 소리가 끊기지 않는다.
- 해제한 곡의 "이름순 자리": 나머지 곡 가운데 이름이 그 곡보다 뒤인 첫 곡 앞. 나머지가 정렬되어 있으면 정확히 제자리이고, 직접 순서를 바꾼 목록이면 가장 가까운 자리.
- 없는·깨진 파일은 즐겨찾기여도 회색이 우선이다.
- 5-C 이름 바꾸기·되돌리기 때 즐겨찾기 경로도 함께 바뀐다(`_rename_everywhere`).
- 라디오 탭에서 Ctrl+D는 아무것도 하지 않는다. 방송국 즐겨찾기는 따로 그대로 둔다.
- MP3 파일과 사용자가 저장한 목록 파일은 건드리지 않는다.

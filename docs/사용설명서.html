my-fun 사용 설명서

내 컴퓨터의 음악과 인터넷 라디오를 듣는 작은 플레이어입니다. 광고가 없고, 내 정보를 어디에도 보내지 않습니다.

처음 시작하기

  1. my-fun.exe를 원하는 폴더에 넣습니다. 설치 과정은 없습니다.
  2. 파일을 더블클릭합니다. 처음에는 창이 뜰 때까지 몇 초 걸립니다.
  3. 곡을 창으로 끌어다 놓으면 준비가 끝납니다.
파란 경고창이 뜨면 "PC 보호" 창이 나올 수 있습니다. 개인이 만든 프로그램이라 Windows가 처음 보는 파일로 여기는 것입니다. 추가 정보를 누른 뒤 실행을 누르세요. 믿을 수 있는 사람에게 받은 파일일 때만 실행하세요.

Windows 10 이상 64비트에서 쓸 수 있습니다. 지우고 싶으면 my-fun.exe 파일을 삭제하면 됩니다.

곡 넣고 듣기

곡 넣기

  • 끌어다 놓기: 곡이나 폴더를 창으로 끌어다 놓으면 목록 뒤에 더해집니다.
  • 열기 지금 목록을 새 곡으로 바꿉니다.
  • 추가 지금 목록 뒤에 더합니다.

두 단추는 재생목록 탭 아래쪽에 있습니다. MP3, FLAC, WAV, OGG, OPUS, M4A, AAC, WMA 파일을 들을 수 있습니다.

재생 단추

  • 가운데 큰 단추로 재생하고 멈춥니다. 양옆은 이전 곡과 다음 곡입니다.
  • 맨 왼쪽은 무작위 재생, 맨 오른쪽은 반복입니다. 반복은 누를 때마다 끔, 전체, 한 곡으로 바뀝니다.
  • 진행 막대를 누르면 그 위치로 갑니다.
  • 제목 옆 하트는 즐겨찾기입니다. 즐겨찾기한 곡은 목록 맨 위로 올라갑니다.

프로그램을 닫았다가 다시 켜면 듣던 목록이 그대로 돌아옵니다.

재생목록

곡을 더블클릭하면 재생합니다. 곡을 오른쪽 클릭하면 재생, 곡 정보 고치기, 즐겨찾기, 지우기를 고를 수 있습니다.

목록 단추로 할 수 있는 일

  • 재생목록과 즐겨찾기를 파일로 저장하고 불러오기
  • 중복 곡 지우기, 없거나 깨진 파일 지우기
  • 이름순, 폴더·이름순 정렬
  • 앨범 그림이 없는 곡을 찾아 붉은 글로 표시하고, 그림 자동으로 찾기
  • 목록 비우기

목록에서 지워도 컴퓨터의 음악 파일은 지워지지 않습니다.

인터넷 라디오

국내외 방송 72개가 들어 있습니다. 묶음을 눌러 펼치고, 방송을 더블클릭하면 연결됩니다.

  • 연결되면 지금 재생 탭에 LIVE 표시와 들은 시간이 나옵니다.
  • 방송이 끊기면 스스로 다시 연결합니다.
  • 주소 넣기… 목록에 없는 방송의 인터넷 주소를 넣을 수 있습니다.
  • 재생 단추를 오른쪽 클릭하면 라디오와 내 음악을 바로 오갑니다.

방송 그림 바꾸기

국내 주요 방송에는 로고가 들어 있습니다. 다른 그림을 쓰고 싶으면 방송을 오른쪽 클릭해 방송 그림 바꾸기를 고르세요. 듣는 중이면 표지를 오른쪽 클릭해도 됩니다.

  1. 이미지 검색을 누르면 브라우저에서 검색이 열립니다.
  2. 마음에 드는 그림을 오른쪽 클릭해 이미지 복사를 고릅니다.
  3. 창으로 돌아와 Ctrl+V를 누릅니다.

그림 파일을 창에 끌어다 놓아도 됩니다. 기본 그림으로 되돌리기를 누르면 원래대로 돌아옵니다.

방송사 사정에 따라 일부 방송은 나오지 않거나 주소가 바뀔 수 있습니다. 라디오를 들으려면 인터넷이 필요합니다.

음향 효과

  1. 켜기 스위치를 켭니다.
  2. 프리셋에서 발라드, 록, 트로트 같은 18가지 음색 중 하나를 고릅니다. 막대를 직접 움직여도 됩니다.
  3. 듣는 곳을 스피커나 이어폰으로 고르면 넓이, 입체감, 베이스를 조절할 수 있습니다.

마음에 들지 않으면 초기화를 누르면 처음으로 돌아갑니다.

작게 보기

일하는 동안 화면을 적게 차지하도록 긴 막대 모양으로 줄입니다. 상단의 작게 보기 단추나 Ctrl+M으로 바꿉니다. 오른쪽 위의 네모 단추를 누르면 원래 크기로 돌아옵니다.

  • 막대의 빈 곳을 끌면 옮겨지고, 양쪽 끝을 끌면 폭이 바뀝니다.
  • 오른쪽 위의 음표와 전파 단추로 곡과 라디오를 바로 오갑니다. 지금 듣는 쪽에 밑줄이 표시됩니다.
  • 오른쪽의 삼선 단추를 누르면 보통 창으로 돌아가 곡 목록이나 방송 목록을 보여 줍니다.
  • 다른 창 위에 항상 떠 있게 하려면 보기 메뉴의 작게 볼 때 항상 위를 켭니다.

색 테마

12가지 색을 고를 수 있습니다. 앨범 표지 양옆에 마우스를 올리면 나타나는 < > 단추로 바로 바꿉니다. 톱니바퀴 모양의 설정 단추를 누르면 목록에서 고를 수 있습니다.

C 앨범 색 테마는 곡의 앨범 그림에서 색을 뽑아 곡마다 색이 바뀝니다.

곡 정보 고치기

저장하면 음악 파일 자체가 바뀝니다. 소중한 파일은 고치기 전에 복사본을 만들어 두세요. 소리는 바뀌지 않습니다.

한 곡 고치기

앨범 표지를 누르거나 Ctrl+I를 누르면 곡 정보 창이 열립니다. 제목, 가수, 앨범을 고치고 저장을 누릅니다.

  • 앨범 그림: 그림 넣기…를 쓰거나, 그림을 끌어다 놓거나, 복사한 뒤 Ctrl+V를 누릅니다.
  • 인터넷에서 찾기: 곡 정보와 앨범 그림을 찾아 빈칸을 채웁니다. 지니나 멜론을 브라우저로 열어 직접 볼 수도 있습니다.
  • 파일 이름: "저장할 때 파일 이름도 바꾸기"를 켜면 가수와 제목으로 이름을 바꿉니다. 잘못 바꿨으면 되돌리기를 누르세요.

여러 곡을 한 번에 고치기

재생목록에서 곡을 여러 개 고르고 Ctrl+T를 누릅니다. MP3 파일만 고칠 수 있습니다.

  • 이름 정리: 파일 이름에서 가수와 제목을 찾아 태그에 넣고, 파일 이름을 "가수 - 제목"으로 맞춥니다.
  • 공통 칸: 앨범, 장르, 그림을 고른 곡 전체에 넣습니다.
  • 그림 찾기: 그림이 없는 곡마다 따로 찾아 넣습니다. 주황 줄은 확실하지 않은 그림이니 보고 골라 주세요.

자주 묻는 질문

소리가 안 나요.
창 아래쪽 소리 막대와 Windows 소리 설정을 확인하세요. 스피커나 이어폰을 바꿨다면 프로그램을 다시 켜 보세요.
"멀티미디어 키를 다른 프로그램이 쓰고 있습니다"라고 나와요.
다른 음악 프로그램이 키보드의 재생 단추를 쓰고 있다는 뜻입니다. 곡을 듣는 데는 문제가 없습니다.
어떤 곡이 흐리게 보이거나 재생되지 않아요.
파일을 옮겼거나 지웠거나 깨진 경우입니다. 목록 메뉴의 없는·깨진 파일 지우기로 정리할 수 있습니다.
라디오가 연결되지 않아요.
인터넷 연결을 확인하고 다른 방송을 틀어 보세요. 해당 방송의 주소가 바뀌었거나 막혔을 수 있습니다.
처음 상태로 되돌리고 싶어요.
프로그램을 닫고, 탐색기 주소창에 %APPDATA%\my-fun을 넣어 그 폴더를 지우세요. 설정과 목록만 지워지고 음악 파일은 그대로입니다.
인터넷으로 무엇을 보내나요?
라디오를 듣거나 곡 정보와 그림을 찾을 때만 인터넷을 씁니다. 찾을 때는 가수와 제목만 씁니다. 사용 기록은 어디에도 보내지 않습니다.
이 프로그램에는 설명서에 적지 않은 숨은 재미가 있습니다. 쓰다 보면 만날지도 모릅니다.

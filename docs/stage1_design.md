# 1단계 설계 — MVP (파일 재생)

> 작성 2026-10-24. 로드맵: `docs/개발로드맵.md`. 시안 이미지: `docs/images/stage1_mockup.png`

## 1. 범위

**만드는 것:**
- B-1 파일·폴더 열기
- B-2 재생·일시정지·정지 (재생 엔진 포함)
- B-3 이전/다음 곡
- B-4 뒤로/앞으로 건너뛰기
- B-5 볼륨·음소거
- C-1 추가/열기와 끌어다 놓기
- J-1 이 기능들의 단축키

**이번에 빼는 것:**
- 반복·무작위, 목록 저장, 목록 편집 → 2-A
- 위치 기억, 곡 정보, 앨범 이미지, 미니 모드 → 2-B
- URL과 라디오 → 3
- 효과 → 4
- 설정 창은 만들지 않는다. 설정은 `settings.json`에서 직접 고친다.

## 2. 지원 형식

- **확장자:** mp3, wav, flac, ogg, opus, m4a, aac, wma. 모두 PyAV가 푸는 형식이다.
- **폴더 추가:** 하위 폴더까지 들어가서 위 확장자만 모은다. 확장자는 대소문자를 가리지 않는다.
- **정렬:** 폴더 경로 순서로 놓고, 같은 폴더 안에서는 파일 이름을 자연 정렬한다(1, 2, 10 순).
- **같은 파일:** 다시 추가하면 그대로 한 번 더 들어간다. 중복 지우기는 2-A에서 한다.

## 3. 화면

시안: `docs/images/stage1_mockup.png`

```
┌ my-fun ─────────────────────────────┐
│ 곡 제목 (파일 이름, 확장자 빼고)       │
│ 01:12 ━━━━━━●──────────────── 03:45 │
│ [⏮] [▶] [■] [⏭]        [🔊] ━━━●──  │
├─────────────────────────────────────┤
│  1  봄날의 산책                      │
│ ▶2  Morning Coffee        (굵게)     │
│  3  Track 03                        │
├─────────────────────────────────────┤
│ [열기 ▾] [추가 ▾] [비우기]       3곡 │
│ 상태 메시지 (오류 등)                 │
└─────────────────────────────────────┘
```

- **제목:** 재생 중인 파일 이름을 확장자 빼고 보여준다. 목록이 비면 "곡을 추가하세요"를 보여준다.
- **시간과 탐색바:**
  - 시간은 경과 / 전체를 m:ss로 보여준다. 한 시간 이상이면 h:mm:ss로 보여준다.
  - 탐색바를 끄는 동안에는 시간 표시만 바뀌고, 놓을 때 그 위치로 이동한다.
  - 막대를 클릭하면 그 위치로 바로 이동한다.
- **버튼:**
  - 이전, 재생/일시정지, 정지, 다음이 있다. 재생/일시정지 버튼은 상태에 따라 아이콘이 바뀐다.
  - 음소거 버튼과 볼륨 슬라이더(0~100)가 있다.
- **목록:**
  - 번호와 파일 이름을 보여준다. 재생 중인 곡은 굵게 쓰고 ▶를 붙인다.
  - 열 수 없었던 곡은 회색으로 보여준다.
  - 더블클릭하면 그 곡을 재생한다.
- **아래 줄:**
  - [열기 ▾]와 [추가 ▾] 메뉴에는 각각 "파일…"과 "폴더…"가 있다.
  - [비우기] 버튼이 있고, 곡 수와 상태 메시지를 보여준다.
- **끌어다 놓기:** 파일이나 폴더를 창에 놓으면 "추가"로 처리한다.
- **아이콘:** Qt 기본 미디어 아이콘(`QStyle.SP_Media*`)을 쓴다. 5.5단계에서 다듬는다.
- **창:** 혼자 실행할 때는 380×480으로 시작하고, 크기를 바꿀 수 있다.

## 4. 단축키

단축키는 플레이어에 포커스가 있을 때만 동작한다(`Qt.WidgetWithChildrenShortcut`). 캘린더에 끼웠을 때 캘린더의 키와 겹치지 않게 하기 위해서다.

| 키 | 동작 |
|---|---|
| Space, X | 재생·일시정지 |
| V | 정지 |
| Z / B | 이전 / 다음 곡 |
| ← / → | 뒤로 / 앞으로 (`player_seek_step`초) |
| ↑ / ↓ | 볼륨 +5 / −5 |
| M | 음소거 켜기/끄기 |
| L | 파일 열기 (목록 바꾸기) |

## 5. 동작 규칙

- **열기:** 목록을 새 곡들로 바꾸고 첫 곡을 재생한다.
- **추가:** 목록 끝에 붙인다. 재생 중이 아니었다면 추가한 첫 곡을 재생한다. 재생 중이었다면 목록에만 붙인다.
- **이전 곡 (B-3):**
  - 재생 위치가 3초 미만이면 이전 곡으로 간다. 첫 곡이면 처음부터 다시 재생한다.
  - 3초 이상이면 현재 곡을 처음부터 재생한다.
  - 매뉴얼에는 "2초 이내 이전 곡, 3초 이후 처음부터"라고 되어 있어 2~3초 사이가 비어 있다. 그래서 3초 하나로 정했다.
- **다음 곡:** 다음 곡으로 간다. 마지막 곡이면 정지한다. 반복은 2-A에서 넣는다.
- **곡이 끝나면:** 다음 곡을 자동 재생한다. 마지막 곡이었다면 정지하고 위치를 0으로 돌린다.
- **정지:** 위치를 0으로 돌리고 출력을 멈춘다. 정지 상태에서 재생을 누르면 현재 곡을 처음부터 재생한다.
- **뒤로/앞으로 (B-4):**
  - `player_seek_step`초만큼 이동한다. 기본값은 5이고 1~100 사이로 제한한다.
  - 0보다 앞으로는 가지 않고 0에서 멈춘다. 곡 끝을 넘으면 다음 곡으로 간다.
- **볼륨 (B-5):**
  - 0~100 사이이고 기본값은 70이다.
  - 실제 크기는 (볼륨/100)²로 계산한다. 귀에 자연스럽게 들리는 곡선이다.
  - 음소거는 볼륨 값을 그대로 두고 소리만 0으로 만든다.
  - 볼륨과 음소거 상태는 바뀔 때마다 저장한다.
- **열 수 없는 파일:**
  - 상태 줄에 "열 수 없음: 파일명"을 띄우고, 목록에서 회색으로 바꾼 뒤 다음 곡으로 간다.
  - 목록 전체가 실패하면 정지한다.
- **비우기:** 정지한 뒤 목록을 비운다.

## 6. 구조와 인터페이스

```
funplayer/
├─ core/
│  ├─ tracks.py     SUPPORTED_EXTS, natural_key(name), expand_paths(paths) -> list[str]
│  ├─ playlist.py   Track(path, failed), Playlist
│  └─ settings.py   DEFAULTS, Settings(store: dict, save: callable), JsonStore(path)
├─ engine/
│  ├─ decoder.py    open_decoder(path) -> Decoder, DecodeError
│  ├─ sink.py       SoundDeviceSink, FakeSink (테스트용)
│  └─ player.py     AudioPlayer (상태: STOPPED / PLAYING / PAUSED)
├─ controller.py    PlayerController (Qt 없음)
├─ ui/
│  ├─ bridge.py     엔진 콜백을 Qt 신호로 바꿔 GUI 스레드로 넘김
│  └─ player_panel.py  PlayerPanel(QWidget)
└─ __main__.py      혼자 실행: JsonStore + PlayerPanel 창
```

- **`Playlist`** (순수 로직)
  - 하는 일: `replace(paths)`, `add(paths) -> 첫 새 곡 번호`, `clear()`, `current`, `set_current(i)`, `next_index() -> int | None`, `prev_target(position) -> ("prev" | "restart", index)`, `mark_failed(i)`
- **`AudioPlayer`** (화면 없음)
  - 하는 일: `load(path)`, `play()`, `pause()`, `stop()`, `seek(sec)`, `set_gain(g)`
  - 읽는 값: `state`, `position`, `duration`
  - 콜백: `on_end()`, `on_error(msg)`
  - 테스트용 장치: 출력(`sink_factory`)과 디코더(`open_decoder`)를 바꿔 끼울 수 있다. `threaded=False`로 만들면 테스트에서 `pump()`를 직접 불러 디코딩을 한 단계씩 진행한다.
- **`PlayerController`**
  - 하는 일: 위 §5 규칙을 모두 담는다. `open`, `add`, `play_index`, `toggle`, `stop`, `next`, `prev`, `seek_by`, `seek_to`, `set_volume`, `toggle_mute`, `on_track_end`, `on_player_error`
  - 테스트: 가짜 플레이어를 끼워서 한다.
- **`PlayerPanel`**: 화면을 그리고, 입력을 컨트롤러에 넘기고, 200ms마다 상태를 다시 그린다. 규칙은 넣지 않는다.
- **`Settings`**
  - 캘린더에서는 캘린더 config dict와 저장 함수를 넘겨받는다. 혼자 실행할 때는 `JsonStore`가 `%APPDATA%\my-fun\settings.json`을 읽고 쓴다.
  - 저장은 임시 파일에 쓴 뒤 바꿔치는 방식이다.
  - 1단계 키: `player_volume`(70), `player_muted`(false), `player_seek_step`(5)
- **로그:** `%APPDATA%\my-fun\logs\funplayer.log`에 남긴다. 파일 하나가 1MB가 되면 새 파일로 넘기고 3개까지 보관한다.

## 7. 엔진 세부

- **출력 형식:** float32 스테레오, 44,100Hz. PyAV `AudioResampler(format="flt", layout="stereo", rate=44100)`가 모노는 스테레오로, 다채널은 스테레오로 바꾼다.
- **버퍼:** numpy 블록을 deque에 쌓아 2초 분량을 유지한다. 가득 차면 디코딩 스레드가 10ms 쉰다.
- **출력 콜백:**
  - 블록 크기는 2048프레임이다.
  - 잠금 안에서 n프레임을 꺼내고, 모자라면 0으로 채운 뒤 소리 크기를 곱한다.
  - 실제로 내보낸 프레임 수를 센다.
- **위치:** 이동 기준점 + 내보낸 프레임 수 ÷ 44,100으로 계산한다. 장치 지연(약 50~100ms)은 무시한다.
- **이동:** 잠금 → 버퍼 비우기 → `decoder.seek(t)` → 기준점 = t, 센 프레임 = 0 → 끝 표시 지우기.
  - PyAV는 키프레임 단위로 이동한다. 그래서 목표 시각까지 풀어서 앞부분을 버리는 방식으로 맞춘다.
- **일시정지·재생:** 출력 스트림을 멈추고 다시 시작한다. 버퍼는 그대로 둔다.
- **정지:** 출력을 멈추고, 버퍼를 비우고, 디코더를 0으로 되돌린다.
- **곡 끝:**
  - 디코더가 끝에 닿고 버퍼까지 다 나가면 상태를 STOPPED로 바꾼다.
  - `on_end()`를 한 번만 부른다. 부르는 곳은 디코딩 스레드이고, 브리지가 GUI 스레드로 넘긴다.
- **오류:**
  - 여는 단계에서 나는 오류는 `DecodeError`로 바꾼다.
  - 재생 도중 디코딩 오류가 나면 곡 끝으로 보고 로그에 경고를 남긴다.
  - 출력 장치 오류(`sounddevice.PortAudioError`)가 나면 `on_error("소리 장치를 열 수 없습니다")`를 부르고 정지한다.

## 8. 테스트

- **테스트 음원:** `tests/conftest.py`에서 PyAV로 3초짜리 사인파 WAV를 만든다. MP3 인코더(libmp3lame)가 있으면 MP3도 만들고, 없으면 MP3 테스트를 건너뛴다.
- **tracks:** 확장자 거르기, 하위 폴더, 자연 정렬.
- **playlist:** 열기/추가, 다음 곡 끝 처리, 이전 곡 3초 규칙, 실패 표시.
- **settings:** 기본값, 범위 제한(볼륨 0~100, 이동 1~100), JSON 왕복, 깨진 JSON이면 기본값.
- **decoder:** 길이, 블록 모양(n, 2)과 float32, 끝, 이동 정확도(±50ms), 깨진 파일이면 DecodeError.
- **player (FakeSink, threaded=False):**
  - 재생하면 위치가 늘고, 일시정지하면 멈춘다.
  - 소리 크기 곱셈이 맞고, 음소거면 0이 나온다.
  - 이동하면 버퍼를 비운다.
  - `on_end`가 한 번만 불린다.
  - 장치 오류가 나면 `on_error`가 불린다.
- **controller (가짜 플레이어):** §5 규칙을 하나씩 확인한다.
- **panel (offscreen):** 만들어지는지, 버튼 상태, 더블클릭하면 재생되는지, 단축키가 컨트롤러를 부르는지.

## 9. 완료 기준 (사용자 체크리스트)

- [ ] `run.bat`로 창이 뜬다
- [ ] MP3 파일을 열면 소리가 나고 시간이 흐른다
- [ ] 폴더를 추가하면 하위 폴더의 곡까지 순서대로 들어간다
- [ ] 재생·일시정지·정지·이전·다음이 버튼과 키로 모두 된다
- [ ] 탐색바 끌기와 ←/→ 이동이 된다
- [ ] ↑/↓ 볼륨과 M 음소거가 되고, 다시 켜도 볼륨이 기억된다
- [ ] 곡이 끝나면 다음 곡으로 넘어가고, 마지막 곡이 끝나면 정지한다
- [ ] 파일을 끌어다 놓으면 추가된다
- [ ] 깨진 파일은 건너뛴다
- [ ] 재생 중에 다른 프로그램을 써도 소리가 끊기지 않는다

## 10. 정한 것 (결정 기록)

- 이전 곡 기준은 3초다.
- 목록 끝에서는 정지한다.
- 이동 단위는 5초이고 `player_seek_step`으로 바꾼다(1~100).
- 볼륨 기본값은 70이고 제곱 곡선을 쓴다.
- 출력은 44.1kHz float32 스테레오다.
- 단축키는 플레이어에 포커스가 있을 때만 동작한다.

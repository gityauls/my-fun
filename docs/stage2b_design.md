# 2-B단계 설계 — 편의 기능

> 작성 2026-10-25. 로드맵: `docs/개발로드맵.md`. 시안 이미지: `docs/images/stage2b_mockup.png`

## 1. 범위

**만드는 것:**
- K-2 끌 때 목록·재생 곡·위치 기억 (켜면 이어 듣기)
- H-1 곡 정보 보기 (제목 아래 가수·앨범 한 줄, [곡 정보] 창)
- H-2 앨범 이미지 표시 (태그 속 그림 → 폴더의 그림 파일 → 기본 그림)
- I-2 작게 보기 (미니 모드)
- J-3 키보드 멀티미디어 키
- J-1 이 기능들의 단축키

**이번에 빼는 것:**
- 태그 고치기, 앨범 이미지 넣기·지우기 → 5단계(자동 태그) 때 함께 본다
- 목록 줄을 "가수 - 제목"으로 보이기(K-3 제목 형식). 목록은 지금처럼 파일 이름이다.
- 실행하면 저절로 재생, 트레이 아이콘, 창 투명도 (K-1, I-6: 고르지 않음)
- 볼륨 멀티미디어 키. Windows가 지금처럼 시스템 볼륨으로 처리한다.

**미리 확인한 것 (2026-10-25, 사용자의 `Test-mp3` 28곡):**
- 이미 쓰는 PyAV로 태그(제목·가수·앨범·년도·장르·트랙)와 태그 속 그림(png, jpg)을 읽을 수 있다. 새 라이브러리가 필요 없다.
- 옛 한글 MP3 절반쯤은 태그가 CP949로 저장되어 있어서 그대로 읽으면 글자가 깨진다. §4.2의 규칙으로 되살리면 "천상천하", "투투", "클럽음악"처럼 바르게 나온다.
- 이 PC에서 재생/일시정지·다음·이전·정지 키를 전역 단축키로 등록할 수 있다 (등록 후 바로 풀었다).

## 4. 규칙

### 4.1 이어 듣기 (K-2)

- **저장하는 것:** 목록, 지금 곡, 재생 위치. 반복·무작위·볼륨은 이미 저장하고 있다.
- **어디에:**
  - 목록은 `%APPDATA%\my-fun\last.m3u8`에 쓴다. 2-A의 m3u8 쓰기를 그대로 쓰므로 경로는 절대 경로다.
  - 지금 곡의 경로와 위치(초)는 `settings.json`에 쓴다.
- **언제:**
  - 끌 때.
  - 곡이 바뀔 때와 목록이 바뀔 때도 쓴다. 갑자기 꺼져도 목록과 마지막 곡은 남는다. 위치는 끌 때만 쓴다.
  - 목록이 비어 있으면 `last.m3u8`을 지우고, 다음에는 빈 목록으로 켜진다.
- **켤 때:**
  - 목록을 불러오고(없는 파일은 2-A처럼 회색), 지난 곡을 지금 곡으로 고르고, 위치를 맞춘다.
  - 저절로 재생하지 않는다. 재생 단추는 [재생] 모양이고, 탐색바와 시간은 그 위치를 보여준다.
  - [재생]이나 `Space`를 누르면 그 위치부터 이어진다. [정지]를 누르면 처음으로 돌아간다.
  - 상태 줄에 "이어 듣기: 1:12부터"를 안내(회색)로 보여준다. 위치가 0이면 보여주지 않는다.
  - 남은 시간이 5초보다 짧으면 처음부터 이어 듣는다.
  - 지난 곡 파일이 없으면 그 줄을 지금 곡으로 두고 위치는 0이다. [재생]을 누르면 2-A처럼 다음 곡으로 넘어간다.
  - 같은 경로가 목록에 여러 번 있으면 첫 번째 줄을 고른다.
- **끄는 옵션은 두지 않는다.** 빈 목록으로 켜고 싶으면 [목록 비우기] 뒤에 끈다.

### 4.2 곡 정보 (H-1)

- **언제 읽나:** 곡이 바뀔 때 그 곡만 읽는다. 목록 전체는 읽지 않는다. 목록 줄과 큰 제목은 지금처럼 파일 이름이다.
- **큰 제목을 파일 이름으로 두는 이유:** 시험한 곡의 태그 제목에 "AudioTrack 02", "02. I Miss You.mp3", "no title" 같은 값이 많았다. 태그 제목은 [곡 정보] 창에서 본다.
- **가수 · 앨범 줄:** 태그의 가수와 앨범을 " · "로 잇는다. 하나만 있으면 그것만 보인다.
- **한글 되살리기:** 태그 글자마다 다음을 차례로 해 본다.
  1. 깨진 바이트(`\udc80`~`\udcff`)가 섞여 있으면: 원래 바이트로 되돌려 CP949로 읽는다.
  2. 모든 글자가 0~255 범위이고 128 이상이 하나라도 있으면: Latin-1 바이트로 되돌려 CP949로 읽어 본다. 실패하면 원래 글자를 쓴다.
  3. 그 밖에는 그대로 쓴다.
  - 1번에서 CP949로도 읽히지 않는 바이트는 �로 바꾼다.
- **못 읽은 칸:** "—"로 보인다. 파일을 아예 열 수 없으면 [곡 정보] 창에 경로·크기만 보인다.
- **[폴더 열기]:** 탐색기를 열고 그 파일을 골라 둔다. 파일이 없으면 폴더를, 폴더도 없으면 단추를 끈다.
- **[곡 정보] 창은 하나만 뜬다.** 열려 있으면 내용만 바뀐다. 곡이 바뀌어도 저절로 따라가지 않는다(본 곡을 계속 보여준다).

### 4.3 앨범 그림 (H-2)

- **고르는 순서:**
  1. 태그 속 그림. 여러 개면 첫 번째.
  2. 같은 폴더의 그림 파일 중 이름이 `cover`, `folder`, `front`, `album`, 또는 태그의 앨범 이름인 것 (확장자 jpg·jpeg·png, 대소문자 무시). 이 순서로 처음 맞는 것.
  3. 폴더에 그림 파일이 딱 하나뿐이면 그것.
  4. 없으면 기본 그림.
- 그림을 읽지 못하면 조용히 기본 그림을 쓴다. 오류로 알리지 않는다.
- 큰 그림은 읽을 때 작게 줄여 둔다. 비율은 지키고 남는 곳은 비운다.
- 같은 곡을 다시 고를 때는 다시 읽는다. 따로 저장해 두지 않는다.

### 4.4 작게 보기 (I-2)

- **바꾸는 법:** [작게 보기] 단추, `Ctrl+M`, [보기 ▾] → 작게 보기. 돌아올 때는 [보통 보기] 단추, `Ctrl+M`, 제목 두 번 클릭.
- **창 크기:** 높이는 작게 보기에 맞춰 고정하고, 폭은 지금 폭을 그대로 쓴다. 폭은 사용자가 바꿀 수 있다.
- **항상 위:** "작게 볼 때 항상 위"가 켜져 있으면(기본) 작게 볼 때만 다른 창 위에 뜬다. 보통 보기에서는 항상 위가 아니다.
- **기억:** 보통 보기와 작게 보기의 창 위치·크기를 따로 기억한다. 끌 때의 모양도 기억해서 다음에는 그 모양으로 켠다. 기억한 위치가 지금 화면 밖이면 화면 가운데에 놓는다.
- **6단계(캘린더) 대비:** 작게 보기는 패널의 모양만 바꾸는 기능(`set_mini(on)`)으로 만든다. 항상 위, 창 크기, 창 위치는 독립 실행 창(`__main__.py`)만 다룬다. 캘린더에 붙일 때는 캘린더가 정한다.

### 4.5 멀티미디어 키 (J-3)

- **전역으로 받는다:** my-fun 창이 앞에 없어도 키가 동작한다. Windows의 전역 단축키로 등록한다.
- **"멀티미디어 키 사용" (기본 켬):**
  - 켜 두면 my-fun이 켜져 있는 동안 다른 프로그램(브라우저 영상 등)은 이 네 키를 받지 못한다.
  - 끄면 등록을 풀고, my-fun 창이 앞에 있을 때만 키를 받는다.
- **다른 프로그램이 먼저 쓰고 있으면:** 등록이 안 된다. 상태 줄에 "멀티미디어 키를 다른 프로그램이 쓰고 있습니다"를 안내로 한 번 보여주고, my-fun 창이 앞에 있을 때만 받는다.
- **키를 꾹 누르고 있어도** 한 번만 동작한다.
- **Windows가 아니면** 아무것도 하지 않는다.
- 끌 때 등록을 푼다.

## 5. 구조와 인터페이스

```
funplayer/
├─ core/
│  ├─ taginfo.py    TrackInfo, fix_text(s), pick_cover(names, album) (새 파일, Qt·PyAV 없음)
│  └─ settings.py   last_track, last_position, mini, mini_on_top, media_keys, 창 위치 두 개
├─ engine/
│  └─ tags.py       read_info(path) -> TrackInfo: PyAV로 태그·형식·태그 속 그림 읽기 (새 파일)
├─ controller.py    이어 듣기 저장·복원, 지금 곡 정보
└─ ui/
   ├─ icons.py      mini_icon, full_icon, note_art (기본 그림)
   ├─ cover.py      앨범 그림 고르기·줄이기 → QPixmap (새 파일)
   ├─ info_dialog.py  TrackInfoDialog (새 파일)
   ├─ media_keys.py   MediaKeys: 전역 단축키 등록·해제, 키 신호 (새 파일, Windows 전용)
   ├─ player_panel.py 머리(그림·가수 줄·작게 보기 단추), [보기 ▾], set_mini(on), 오른쪽 클릭 "곡 정보…"
   └─ (__main__.py)   항상 위, 창 위치 기억, 켤 때 복원·끌 때 저장 연결
```

- **`TrackInfo`** (dataclass): `path`, `title`, `artist`, `album`, `year`, `genre`, `track`, `duration`, `codec`, `bitrate`, `sample_rate`, `channels`, `size`, `picture: bytes | None`. 비어 있는 칸은 빈 문자열이나 None이다.
- **`fix_text(s)`:** §4.2의 한글 되살리기. 순수 함수라 테스트하기 쉽다.
- **`pick_cover(names, album)`:** 폴더의 파일 이름 목록에서 §4.3의 2~3번 규칙으로 고른 이름을 돌려준다(없으면 None).
- **`read_info(path)`:** 파일을 열어 TrackInfo를 채운다. 열 수 없으면 경로·크기만 채워 돌려준다. 예외를 밖으로 내지 않는다.
- **`PlayerController`:**
  - 더하는 것: `save_session(list_path)`, `restore_session(list_path)`, `info` (지금 곡의 TrackInfo, 곡이 바뀔 때 읽는다), `info_for(index)`
  - `restore_session`은 목록을 불러오고 지난 곡을 고르고 위치를 맞추되 재생하지 않는다. 그 뒤 [재생]은 그 위치부터다.
  - Qt를 import하지 않는다. 저장 경로는 밖에서 넘겨받는다.
- **`MediaKeys`:**
  - `enable()`, `disable()`, 신호 `play_pause`, `next`, `prev`, `stop`.
  - `enable()`은 등록에 실패한 키가 있으면 False를 돌려준다.
  - Windows API는 넘겨받을 수 있게 해서, 테스트에서는 가짜로 바꾼다.
- **`PlayerPanel`:** 화면에는 규칙을 넣지 않는다(1단계와 같다). `set_mini(on)`은 위젯을 숨기고 보이기만 한다.
- **`Settings`:**
  - `player_last_track` (""), `player_last_position` (0.0, 0 이상)
  - `player_mini` (false), `player_mini_on_top` (true), `player_media_keys` (true)
  - `player_geometry`, `player_mini_geometry` ([x, y, 폭, 높이] 또는 없음)
  - 잘못된 값은 기본값으로 본다.

## 6. 테스트

- **taginfo:**
  - `fix_text`: 깨진 바이트가 섞인 CP949, Latin-1로 읽힌 CP949, 바른 UTF-8 한글, 영문, CP949로도 안 읽히는 바이트
  - `pick_cover`: 이름 순서(`cover` > `folder` > `front` > `album` > 앨범 이름), 대소문자, 그림이 하나뿐인 폴더, 그림이 여럿이고 이름이 안 맞는 폴더
- **tags (테스트에서 만든 작은 파일):** 태그가 있는 파일, 없는 파일, 열 수 없는 파일, 태그 속 그림이 있는 파일
- **settings:** 새 키 기본값과 잘못된 값
- **controller (가짜 플레이어):**
  - 저장 → 복원 왕복: 같은 목록·같은 곡·같은 위치이고 재생하지 않는다, 그 뒤 [재생]은 그 위치부터
  - 남은 시간이 5초 미만, 지난 곡 파일이 없음, 같은 경로가 여러 줄, 저장 파일이 없거나 깨짐, 빈 목록이면 파일 지우기
  - 곡이 바뀔 때·목록이 바뀔 때 저장
  - `info`가 곡이 바뀔 때 바뀌는지
- **media_keys (가짜 Windows API):** 등록·해제, 실패한 키, 키 메시지가 알맞은 신호를 내는지, 끌 때 해제
- **panel (offscreen):**
  - 가수·앨범 줄, 기본 그림과 태그 속 그림
  - `set_mini`가 숨기고 보이는 위젯, `Ctrl+M`, 제목 두 번 클릭
  - [보기 ▾] 메뉴 항목과 체크 상태, 오른쪽 클릭 "곡 정보…"
  - [곡 정보] 창의 칸, 하나만 뜨는지, [폴더 열기]가 탐색기를 부르는지(가짜로 바꿔서)
- **__main__:** 창 위치 복원(화면 밖이면 가운데), 작게 볼 때만 항상 위

## 7. 완료 기준 (사용자 체크리스트)

- [ ] 곡을 듣다가 끄고 다시 켜면 같은 목록·같은 곡·같은 위치가 준비되어 있고, [재생]을 누르면 거기서 이어진다
- [ ] 제목 아래에 가수·앨범이 나오고, 옛 한글 MP3도 글자가 깨지지 않는다
- [ ] `Ctrl+I`, 그림 클릭, 오른쪽 클릭 "곡 정보…"로 [곡 정보] 창이 열리고, [폴더 열기]가 탐색기에서 그 파일을 보여준다
- [ ] 그림이 든 MP3는 그 그림이, 폴더에 `cover.jpg` 같은 그림이 있으면 그 그림이, 둘 다 없으면 기본 그림이 나온다
- [ ] `Ctrl+M`과 단추로 작게 보기 ↔ 보통 보기가 바뀌고, 작게 볼 때 다른 창 위에 떠 있다
- [ ] 작게 본 채로 끄고 켜면 작게 보기로, 같은 자리에 켜진다
- [ ] 다른 프로그램을 쓰는 중에도 재생/일시정지·다음·이전·정지 키가 my-fun을 움직인다
- [ ] "멀티미디어 키 사용"을 끄면 브라우저 영상 같은 다른 프로그램이 그 키를 다시 받는다

## 8. 정한 것 (결정 기록)

- 목록·지금 곡·위치를 끌 때와 곡·목록이 바뀔 때 저장한다. 켜면 그 위치에서 멈춰 있고 저절로 재생하지 않는다.
- 이어 듣기를 끄는 옵션은 두지 않는다.
- 큰 제목과 목록은 파일 이름 그대로 둔다. 태그는 가수·앨범 한 줄과 [곡 정보] 창에서 보여준다.
- 태그는 지금 곡만 읽는다. 목록 전체를 읽지 않는다.
- 옛 한글 태그(CP949)를 되살린다.
- 태그와 그림은 보기만 한다. 고치기는 5단계 때 본다.
- 앨범 그림은 태그 속 그림 → 폴더의 정해진 이름 → 폴더에 하나뿐인 그림 → 기본 그림 순서다.
- 작게 보기는 같은 창이 작아지는 방식이다. 따로 뜨는 두 번째 창을 만들지 않는다.
- 작게 볼 때만 항상 위다(옵션, 기본 켬). 보통·작게의 창 위치를 따로 기억한다.
- 멀티미디어 키는 전역으로 받고, 끌 수 있다(기본 켬). 볼륨 키는 Windows에 맡긴다.
- 새 메뉴 단추는 이름이 보이는 [보기 ▾]로 한다. 아이콘만 있는 단추로 숨기지 않는다(2-A 확인 때 "저장…"을 찾기 어려웠던 일을 반영).
- 새 라이브러리를 넣지 않는다. 태그와 그림은 이미 쓰는 PyAV로 읽는다.

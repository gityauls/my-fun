# 3단계 설계: 인터넷 라디오

> 시안: `docs/images/stage3_mockup.png` (사용자 의견 반영 2026-10-26) · 로드맵: `docs/개발로드맵.md` §3 R-1, B-1(URL)

## 1. 범위

- **R-1 인터넷 라디오:** 방송국 목록, 재생, 끊기면 다시 연결.
- **B-1 URL 열기:** 방송 주소를 직접 넣어 듣기.
- **방송은 세 가지다.**
  - 국내 방송사: KBS 1라디오, KBS 해피FM, KBS 쿨FM, KBS 클래식FM, MBC 표준FM, MBC FM4U.
  - 해외 인터넷 라디오: 장르별 추천 방송을 처음부터 목록에 넣어 둔다. 장르는 최대한 다양하게 하고, 장르마다 2개 이하다(사용자 의견 2026-10-26).
  - 직접 넣은 주소.
- **듣기 시작은 방송국 줄을 한 번 누르는 것이다.** 탭을 누르거나 앱을 켜는 것만으로는 소리도 접속도 시작하지 않는다(잘못 누름 방지, 사용자 의견).
- **완료 기준 (로드맵):** 고른 방송국이 30분 이상 끊김 없이 나온다.
- **넣지 않는 것:**
  - 해외 방송 검색 창, 장르를 골라 보는 설정 — 쓰면서 필요하면 "체크한 장르만 보이기" 설정으로 더한다.
  - 녹음.
  - 안정화 뒤 할 일로 미룸(로드맵에 적는다): 방송사 편성표, 방송국 아이콘, 정해진 시간에 라디오 켜기.
  - SBS: 주소는 받아지지만 방송사 서버가 재생을 막는다(시험 2026-10-26, 403). 접근 제한은 우회하지 않는다.
- **미리 시험한 것 (2026-10-26, 이 PC):**
  - KBS 1라디오·쿨FM·클래식FM과 MBC 표준FM·FM4U는 방송사 웹 재생 주소를 받아 PyAV로 바로 풀렸다. 모두 HLS AAC이다.
  - radio-browser 검색으로 찾은 MP3 방송도 풀렸다.
  - 새 라이브러리는 필요 없다. 주소 받기는 표준 라이브러리 `urllib`로 한다.

## 2. 화면

- **탭:**
  - 목록 위에 [재생목록] [라디오] 탭을 둔다.
  - 탭을 바꿔도 지금 나오는 소리는 그대로다. 보이는 목록만 바뀐다.
  - 마지막에 본 탭을 기억한다.
- **라디오 탭의 목록:** 접고 펼 수 있는 묶음이다.
  - 순서: "★ 즐겨찾기" → "국내 방송" → "해외 추천 · 장르 (2)" 묶음들 → "직접 넣은 방송".
  - 즐겨찾기·국내 방송·직접 넣은 방송은 펼쳐져 있고, 해외 장르 묶음은 처음에 접혀 있다. 펼침 상태는 기억한다.
  - 한 줄에 방송국 이름과 회색 출처(`KBS`, `MBC`, 나라 이름, `직접 넣음`)가 보인다.
  - 지금 방송국 줄에는 ▶와 굵은 글씨가 붙는다.
  - **방송국 줄을 한 번 누르면 듣는다.** `Enter`도 같다. 묶음 줄을 누르면 접고 펴기만 한다.
- **아래 줄 (라디오 탭):** [주소 넣기…] [보기 ▾], 그리고 "방송 N개"가 보인다. 재생목록 탭의 [열기] [추가] [목록]은 숨긴다.
- **라디오를 들을 때의 머리 줄:**
  - 큰 제목은 방송국 이름이다.
  - 그 아래 회색 줄은 "지금: 곡 이름"이다. 방송이 곡 이름을 보내 줄 때만 보이고, 아니면 비운다.
  - 그림은 라디오 기본 그림이다(직접 그린 것).
- **탐색 줄:**
  - 탐색바 대신 왼쪽에 빨간 "● LIVE", 오른쪽에 "들은 시간 m:ss"를 둔다.
  - 멈추면 LIVE는 회색이 된다.
  - 반복·무작위 단추는 흐리게(끔) 보인다.
- **작게 보기:** 2-B와 같다. 라디오일 때는 탐색바 자리를 숨긴다.
- **오른쪽 클릭 (방송국 줄):** 듣기 · 즐겨찾기 ★ · 이름 바꾸기… · 지우기, 그리고 구분선 아래에 "기본 방송 다시 보이기"가 있다.
  - 기본 방송을 지우면 숨기기만 한다. "기본 방송 다시 보이기"로 되살린다.
- **[주소 넣기…] 창:**
  - 이름과 주소 칸이 있다.
  - "http·https 방송 주소, .m3u·.pls·.m3u8 주소를 넣을 수 있습니다." 안내를 둔다.
  - 단추는 [넣기] [취소]이다. 이름을 비워 두면 주소의 호스트 이름을 쓴다.
- **상태 줄 문구 (회색 안내):**
  - "연결 중…"
  - "KBS 쿨FM에 연결했습니다"
  - "다시 연결하는 중… (2/3)"
  - "이어 듣기: KBS 쿨FM"
- **안 될 때 문구 (회색 안내, 빨간 오류로 겁주지 않는다 — 사용자 의견):**
  - 연결 실패: "지금은 이 방송을 들을 수 없습니다. 다른 방송을 골라 보세요"
  - 이 문구는 사용자가 방송을 누른 뒤에만 나온다. 켤 때·탭을 바꿀 때는 접속하지 않으므로 어떤 오류도 나오지 않는다.
- **[주소 넣기…] 창 안의 오류(창 안 빨간 글씨):** "주소가 올바르지 않습니다"

## 3. 단축키

- 기존 키는 그대로다. `Space`는 재생/멈춤이고, 라디오에서는 멈춘 뒤 다시 누르면 다시 연결한다.
- `Ctrl+Tab`은 [재생목록] ↔ [라디오] 탭을 바꾼다.
- 라디오를 듣는 중에 [이전]/[다음], `Ctrl+←`/`Ctrl+→`, 멀티미디어 ⏮⏭ 키를 누르면 라디오 목록의 위/아래 방송국으로 옮긴다. 보고 있는 탭과 상관없이 지금 나오는 소리를 기준으로 한다.
- 라디오에서는 탐색 키(`←`/`→`)가 아무것도 하지 않는다.

## 4. 규칙

### 4.1 방송국 목록

- **기본 방송**은 코드 안에 있다. 각각 이름, 출처, "주소 받는 방법"과 채널 값을 가진다.
  - 국내 6개: KBS 1라디오(21), 해피FM(22), 클래식FM(24), 쿨FM(25), MBC 표준FM(`sfm`), FM4U(`mfm`)
  - 해외 추천: 장르마다 2개 이하, 장르는 최대한 다양하게(예: Lo-fi, 재즈, 클래식, 팝, 록, 일렉트로닉, 앰비언트, 라운지·칠아웃, 피아노, 영화음악, 라틴, 레게, 블루스, 컨트리, 힙합, K-pop, 80년대, 보사노바).
- **해외 추천 고르는 규칙 (구현 때 한 번, 그 뒤 필요할 때):**
  - radio-browser.info의 장르별 인기 순 방송에서 고른다. 실제로 3초 이상 소리가 풀리는 것만 넣는다.
  - 이름이 장르와 맞고, 주소에 사용 기한 같은 일회성 값이 없고, MP3·AAC 64 kbps 이상인 것만 넣는다.
  - 맞는 방송이 1개뿐인 장르는 1개만 둔다. 0개면 그 장르를 뺀다.
  - 목록은 코드 안의 고정 목록이다. 앱이 radio-browser에 접속하지 않는다. 확인 스크립트(`tools/check_stations.py`)로 언제든 다시 확인한다.
  - 2026-10-26 시험에서 18개 장르 모두 2개씩 소리가 나는 방송이 있었다(장르와 안 맞는 것은 구현 때 바꾼다).
- **사용자 목록:** `%APPDATA%\my-fun\stations.json`에 저장한다(UTF-8 JSON). 담는 것은 넣은 방송, 즐겨찾기, 이름 바꾼 것, 숨긴 기본 방송, 순서이다.
  - 파일이 없거나 깨졌으면 기본 방송만으로 시작한다. 깨진 파일은 `stations.json.bak`으로 옮겨 둔다.
- **순서:** ★ 방송은 "즐겨찾기" 묶음에 모인다(원래 묶음에서는 빠진다). 각 묶음 안은 사용자가 끌어 놓은 순서다. 묶음 사이로는 끌 수 없다.
- **같은 주소를 다시 넣으면** 새 줄을 만들지 않고 그 줄을 고른다. 안내는 "이미 목록에 있습니다"이다.

### 4.2 주소 받기와 연결

- **주소 받는 방법** (방송사별로 바꿔 끼울 수 있게 따로 둔다):
  - KBS: `https://cfpwwwapi.kbs.co.kr/api/v1/landing/live/channel_code/{코드}` JSON의 `channel_item[].service_url`.
  - MBC: `https://sminiplay.imbc.com/aacplay.ashx?agent=webapp&channel={채널}` 응답 글자(Referer `https://mini.imbc.com/`).
  - 직접 넣은 주소와 해외 추천 방송: 주소 그대로 쓴다. `.m3u`/`.pls`면 파일을 받아 첫 http(s) 주소를 쓴다. `.m3u8`(HLS)은 그대로 PyAV에 넘긴다.
- **언제 접속하나:** 방송국을 들을 때(방송국 줄 클릭, `Enter`, 라디오를 멈춘 뒤 [재생], 라디오 중 다음/이전)만 접속한다. 켤 때와 탭을 바꿀 때는 접속하지 않는다.
- **뒤에서 한다:** 주소 받기와 연결은 작업 스레드에서 한다. 그동안 "연결 중…"을 보이고 화면은 멈추지 않는다.
  - 기다리는 동안 다른 방송국을 고르면 앞의 시도는 버린다. 늦게 끝나도 무시한다.
- **시간 제한:** 주소 받기는 10초, 연결은 15초다.
- **User-Agent:** `my-fun/0.3 (+local player)`. 국내 방송 주소 받기에서 방송사가 막으면 일반 브라우저 문자열을 쓴다.
- **모아 두기:**
  - 라디오는 소리를 8초쯤 미리 받아 둔 뒤 낸다. 파일은 지금처럼 2초다.
  - 처음 소리가 나기까지 1~3초쯤 걸릴 수 있다.

### 4.3 끊김과 다시 연결

- **끊김이란:** 방송에서 데이터가 15초 넘게 오지 않거나, 연결이 끝나거나, 풀기 오류가 나는 것이다.
- **다시 연결:**
  - 모아 둔 소리가 남아 있는 동안 뒤에서 다시 연결한다. 2초, 4초, 8초 간격으로 3번까지 한다.
  - 국내 방송은 매번 주소를 새로 받는다. 주소 안의 사용 기한이 지났을 수 있기 때문이다.
  - 다시 이어지면 안내 없이 계속 나온다. "들은 시간"도 이어진다.
- **처음 연결이 안 되거나 3번 모두 실패하면** 멈춤 상태가 되고 회색 "지금은 이 방송을 들을 수 없습니다. 다른 방송을 골라 보세요"를 보인다. 저절로 다음 방송으로 넘어가지 않는다.
- **완료 기준:** 30분 동안 끊김 없이 나온다. 다시 연결 때문에 소리가 잠깐 비는 것도 끊김으로 본다.

### 4.4 재생 규칙

- **재생/멈춤:** 라디오는 생방송이다.
  - 멈춤을 누르면 연결을 끊는다.
  - 다시 누르면 지금 나오는 방송에 새로 연결한다. 뒤처진 데서 이어 듣지 않는다.
  - [정지]도 같은데, "들은 시간"을 0으로 되돌린다.
- **반복·무작위:** 라디오에서는 쓰지 않는다(흐리게 보임). 설정값은 바뀌지 않는다.
- **곡과 라디오 오가기:**
  - 곡을 듣다가 방송국을 고르면 곡은 멈추고, 그 곡과 위치를 기억한다.
  - 재생목록 탭에서 [재생]을 누르거나 곡을 고르면 라디오를 끊는다.
  - 기억한 곡을 다시 [재생]하면 그 위치부터 이어진다(2-B의 이어 듣기 대기 상태를 다시 쓴다).
- **[재생] 단추:** 지금 나오는 쪽을 기준으로 한다. 라디오를 듣다가 멈췄으면 [재생]은 그 방송국을 다시 연결한다. 보고 있는 탭은 상관없다.
- **이어 듣기 (2-B K-2와 함께):**
  - 라디오를 듣다가 끄면, 다음에 켤 때 그 방송국이 골라진 채 멈춰 있고 라디오 탭이 보인다.
  - 상태 줄에 "이어 듣기: KBS 쿨FM"이 나온다. 접속은 하지 않는다. [재생]을 누르면 연결한다.
  - 재생목록과 곡 위치도 2-B처럼 따로 저장되어 있어서, 재생목록으로 돌아가면 이어 들을 수 있다.
- **"지금:" 곡 이름:**
  - 방송이 곡 이름을 보내 주면(ICY `StreamTitle`, HLS ID3 `TIT2`) 보여준다. 바뀌면 바로 따라 바뀐다.
  - 못 받으면 줄을 비운다. 구현 계획에서 PyAV로 받을 수 있는지 먼저 확인하고, 안 되면 이 줄은 빈 채로 둔다(완료 기준 아님).
- **[곡 정보] (`Ctrl+I`, 그림 클릭):** 라디오일 때는 방송국 이름, 출처, 형식·음질(연결된 뒤), 주소를 보인다.
  - 국내 방송의 주소 칸은 "방송사 웹 재생 주소 (들을 때마다 새로 받음)"이다. 매번 바뀌는 주소라서 그대로 보여주지 않는다.

### 4.5 [주소 넣기…]

- `http://` 또는 `https://`로 시작해야 한다. 아니면 "주소가 올바르지 않습니다"를 보이고 창은 닫히지 않는다.
- [넣기]를 누르면 목록에 넣고 바로 듣는다. 듣기에 실패해도 목록에는 남는다. 주소가 잠깐 안 될 수도 있기 때문이다.

## 5. 구조와 인터페이스

```
funplayer/
├─ core/
│  ├─ stations.py   Station, BUILTIN_STATIONS, StationList (순서·★·숨김·넣기·지우기·이름), load/save JSON (새 파일, Qt·네트워크 없음)
│  └─ settings.py   last_source ("file"|"radio"), last_station (id), tab ("playlist"|"radio")
├─ engine/
│  ├─ resolve.py    resolve(station, fetch) -> str: 방송사별 주소 받기, .m3u/.pls 풀기 (새 파일, fetch는 넘겨받음)
│  └─ player.py     load(url, live=True): 8초 모으기, 끊김 알림, duration 0, 탐색 없음
├─ radio.py         RadioController: 연결·다시 연결 상태, 들은 시간, "지금:" 곡 이름 (Qt 없음, 작업 실행기는 넘겨받음)
├─ controller.py    곡 ↔ 라디오 오가기, 이전/다음/재생의 대상, 이어 듣기 저장·복원에 라디오 더하기
└─ ui/
   ├─ station_view.py  방송국 목록 위젯 (묶음 접기·펴기, 한 번 클릭 = 듣기, ★, 출처, 묶음 안 끌어 옮기기, 오른쪽 클릭)
   ├─ radio_dialogs.py  AddUrlDialog (새 파일)
   ├─ worker.py      작업 스레드 실행기 (QThreadPool) — 결과는 UI 스레드로 돌려준다
   ├─ icons.py       radio_art(size)
   └─ player_panel.py  탭, 라디오 탭 아래 줄, LIVE 줄, 상태 문구
```

- **네트워크는 `fetch(url, headers) -> bytes` 함수 하나로만 한다.** 테스트에서는 가짜 fetch로 바꾼다. 테스트는 인터넷에 접속하지 않는다.
- **`RadioController`:**
  - `play(station)`, `stop()`, `toggle()`.
  - 신호 대신 콜백을 쓴다. 상태는 `IDLE`/`CONNECTING`/`LIVE`/`RETRYING`/`FAILED`이다.
  - `elapsed`, `now_title`.
  - 작업 실행기와 시계를 넘겨받아, 테스트에서 시간을 앞당길 수 있다.
- **플레이어의 라이브 모드:**
  - 끊김은 `pump()`가 알린다(`stream_lost`). 다시 연결은 `RadioController`가 한다.
  - 모아 둔 소리가 남아 있는 동안 새 연결을 붙인다.
- **층 나누기:** core/·engine/·controller.py·radio.py는 Qt를 import하지 않는다(test_layering에 radio.py를 더한다).

## 6. 테스트

- **stations:**
  - 기본 방송과 사용자 방송 합치기, ★ 맨 위, 숨기기·되살리기, 이름 바꾸기, 같은 주소, 순서 저장.
  - 깨진 JSON → `.bak`, 모르는 칸은 무시.
- **resolve (가짜 fetch):**
  - KBS JSON, MBC 글자, `.m3u`, `.pls`, `.m3u8` 그대로, 잘못된 응답.
  - 시간 초과는 오류로 처리한다.
- **해외 추천 목록:** 장르마다 2개 이하, 주소 중복 없음, http(s) 주소. 실제 소리 확인은 `tools/check_stations.py`(인터넷 필요, 자동 테스트 아님).
- **player 라이브 모드:**
  - 테스트 안에서 띄운 `localhost` HTTP 서버가 MP3를 천천히 흘려 보내는 방식으로 시험한다.
  - duration 0, 탐색 불가, 끊으면 `stream_lost`.
- **RadioController (가짜 플레이어·가짜 시계):**
  - 연결 성공, 다시 연결 2·4·8초와 국내 방송 주소 새로 받기, 3번 실패 → FAILED와 문구.
  - 기다리는 중 다른 방송 고르기 → 앞 결과 무시.
  - 멈춤 → 다시 연결, 들은 시간.
- **controller:**
  - 곡 → 라디오 → 곡에서 위치가 이어진다.
  - 라디오 중 이전/다음은 방송국을 옮긴다.
  - 이어 듣기: 라디오로 끄고 켜면 방송국이 골라지고 접속은 없다.
- **panel (offscreen):**
  - 탭을 바꿔도 플레이어·네트워크를 부르지 않는다(가짜 fetch 호출 0번).
  - 방송국 줄 한 번 클릭 = 듣기, 묶음 줄 클릭 = 접고 펴기만.
  - 아래 줄 단추, LIVE 줄, 반복·무작위 흐림, 오른쪽 클릭 메뉴, 실패 문구가 회색인지.
  - [주소 넣기] 창의 칸과 오류 문구.
  - 작게 보기에서 탐색바를 숨기는지.
- **실제 방송 확인 (자동 테스트 아님):** 구현 뒤 실제 캡처 때 KBS·MBC·해외 한 곳씩 10초 듣기 스크립트를 따로 돌린다.

## 7. 완료 기준 (사용자 체크리스트)

- [ ] [라디오] 탭을 눌러도 아무것도 켜지지 않고, 방송국 줄을 한 번 누르면 들린다
- [ ] KBS·MBC 방송을 들을 수 있고, "● LIVE"와 들은 시간이 보인다
- [ ] 고른 방송이 30분 이상 끊김 없이 나온다
- [ ] 해외 추천 장르를 펼쳐 여러 장르의 방송을 들을 수 있다 (장르마다 2개 이하)
- [ ] 안 되는 방송을 누르면 회색으로 "다른 방송을 골라 보세요" 안내가 나온다
- [ ] [주소 넣기…]로 방송 주소를 넣어 들을 수 있고, 잘못된 주소는 안내가 나온다
- [ ] 멈췄다가 다시 누르면 지금 나오는 방송으로 이어진다
- [ ] 와이파이를 잠깐 껐다 켜면(또는 선을 뽑았다 꽂으면) 다시 연결되고, 오래 끊기면 회색 안내가 나온다
- [ ] ★ 즐겨찾기, 이름 바꾸기, 지우기(기본 방송은 숨기기), 끌어서 순서 바꾸기가 되고 껐다 켜도 남아 있다
- [ ] 라디오를 듣다가 끄고 켜면 그 방송국이 골라진 채 멈춰 있고, [재생]을 누르면 나온다
- [ ] 곡을 듣다가 라디오로 갔다가 돌아와 [재생]하면 듣던 곡 위치에서 이어진다
- [ ] 라디오를 들을 때 [이전]/[다음]과 멀티미디어 키로 방송국이 바뀌고, 작게 보기에서도 된다

## 8. 정한 것 (결정 기록)

- 국내 방송사, 해외 인터넷 라디오, 직접 넣은 주소를 모두 듣는다(사용자 선택).
- 방송국 목록은 목록 위 탭에 둔다(사용자 선택). 탭은 목록만 바꾸고, 방송국 줄을 한 번 눌러야 듣기 시작이다(사용자 의견, 잘못 누름 방지).
- 해외 방송은 검색 창 대신 장르별 추천(장르마다 2개 이하, 장르는 다양하게)을 처음부터 넣어 둔다(사용자 의견). 장르 고르기 설정은 쓰면서 필요하면 더한다.
- 안 될 때는 빨간 오류 대신 회색 "다른 방송을 골라 보세요" 안내다. 누르기 전에는 접속하지 않아서 오류가 먼저 보이지 않는다(사용자 의견).
- 편성표, 방송국 아이콘, 정해진 시간에 켜기는 안정화 뒤 할 일로 미룬다(사용자 의견).
- SBS는 방송사가 외부 재생을 막아 둔 것이라, 앱 분석 등으로 우회하지 않는다.
- 국내 기본 방송은 KBS 4개, MBC 2개다. SBS는 서버가 재생을 막아 뺀다. 접근 제한은 우회하지 않는다.
- 방송사별 "주소 받기"를 따로 둬서 바뀌면 그 부분만 고친다.
- 재생 엔진은 지금 것을 넓혀 쓴다. 새 라이브러리를 넣지 않는다(PyAV + `urllib`).
- 라디오의 멈춤은 연결 끊기이고, 다시 누르면 지금 방송으로 새로 연결한다.
- 라디오는 8초 모아 두고, 끊기면 3번(2·4·8초) 다시 연결한다. 국내 방송은 주소를 새로 받는다.
- 켤 때와 탭을 바꿀 때는 인터넷에 접속하지 않는다. 방송을 들을 때만 접속하고, 방송을 받는 것 말고는 아무것도 보내지 않는다.
- 곡 ↔ 라디오를 오가면 곡 위치를 기억해 이어 듣는다.
- 이전/다음과 재생은 보고 있는 탭이 아니라 지금 나오는 쪽을 따른다.
- "지금:" 곡 이름은 받을 수 있을 때만 보인다(완료 기준 아님).
